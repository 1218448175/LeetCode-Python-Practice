## 目标

同步并更新远程和本地代码，撰写题解，保持git版本整洁

## 工作流程

1.先pull拉取远程代码到本地的main分支（个人小项目，不用多分支），根目录下会多出一题目文件夹

2.将题目文件夹移动到`题目目录/`下（与历史题目保持一致）

3.根据题目文件夹中的py文件，在md文档中撰写题解。题解的格式请你参考`题目目录/`下任意其他题目的题解格式（只读取一份其他题解作为参考）

4.在根目录的READEME.md中正确的分类下添加这一题的条目，这一题的分类请参考leetcode官网，如果md文档中没有该分类，请你参考其他分类的格式添加这一分类

5.通过git log查看最近10条log

6.通过log分析找出所有属于这一题的提交记录，与未提交的部分合并成一个提交，备注的格式参考其他提交

7.通过git push --force提交到远程仓库

## 注意

- 如果工作流中出现任何错误，请及时停止工作并汇报发生错误的地方

- WebFetch 无法直接访问 LeetCode 官网（leetcode.cn / leetcode.com），原因是 Anthropic 服务端存在网络限制。如需获取题目描述、难度、示例等信息，请改用 WebSearch 搜索「leetcode + 题号 + 题名」

- 在push 到远程仓库前请通知我
