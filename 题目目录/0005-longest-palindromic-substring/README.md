## [5. 最长回文子串](https://leetcode.cn/problems/longest-palindromic-substring/)

### 中等

给你一个字符串 `s`，找到 `s` 中最长的回文子串。

回文串是指正读和反读都一样的字符串。

<p><strong>示例 1:</strong></p>
<pre><strong>输入:</strong> s = "babad"
<strong>输出:</strong> "bab"
<strong>解释:</strong> "aba" 同样是符合题意的答案。
</pre>

<p><strong>示例 2:</strong></p>
<pre><strong>输入:</strong> s = "cbbd"
<strong>输出:</strong> "bb"
</pre>

---

## 题解：动态规划 — 按子串长度递推

### 1. 核心思路：区间 DP 的回文判定

这道题是经典的**区间 DP** 问题。定义 `dp[l][r]` 表示子串 `s[l:r+1]` 是否为回文串。

回文串具有天然的递推性质：若 `s[l:r+1]` 是回文串，则去掉首尾后 `s[l+1:r]` 也必是回文串。反过来：

$$dp[l][r] = dp[l+1][r-1] \land (s[l] = s[r])$$

即一个子串是回文串，当且仅当：
1. 去掉首尾后的内部子串是回文串
2. 首尾两个字符相同

边界条件（base case）：
- **单字符**（`l == r`）：必为回文，`dp[l][l] = True`
- **双字符**（`r - l == 1`）：首尾相同即为回文，`dp[l][r] = (s[l] == s[r])`

---

### 2. 遍历顺序：按子串长度从小到大

本题代码的核心设计在于**遍历顺序**。外层循环 `i` 控制子串长度（`i = r - l`），内层循环 `l` 枚举左端点：

```python
for i in range(1, n):          # i = 子串长度（偏移量）
    for l in range(n):         # l = 左端点
        r = l + i              # r = 右端点
```

为什么必须按长度递增？

因为 `dp[l][r]` 依赖 `dp[l+1][r-1]`（长度比当前短 2 的内部子串），按长度从小到大递推能保证被依赖的状态已经计算完成。这是区间 DP 的标准遍历策略。

---

### 3. 代码中的巧思：全 True 初始化

```python
dp = [[True for _ in range(n)] for _ in range(n)]
```

这段初始化将整个 DP 矩阵全部设为 `True`，而非通常的只设对角线。这带来了两个好处：

**好处一：单字符 base case 天然满足。** 由于循环从 `i = 1`（长度 ≥ 2）开始，所有 `dp[l][l]` 永远不会被访问修改，始终保持初始值 `True`。无需额外写对角线的初始化循环。

**好处二：答案默认值天然合理。** `max_len_l = 0, max_len_r = 0` 表示第一个字符 `s[0]` 作为初始最优解。对于任何非空字符串，单个字符一定是回文，故这个默认值始终合法。

---

### 4. 变量设计与迭代推演

| 变量 | 含义 | 初始值 |
|------|------|--------|
| `n` | 字符串长度 | `len(s)` |
| `dp` | `dp[l][r]` 表示 `s[l:r+1]` 是否回文 | 全 `True` 矩阵 |
| `i` | 外层循环变量，子串偏移量（即 `r - l`） | `1` 到 `n-1` |
| `max_len_l` | 当前最长回文子串的左端点 | `0` |
| `max_len_r` | 当前最长回文子串的右端点 | `0` |

以 `s = "babad"` 为例的推演过程：

**i = 1（长度 2 的子串）：**

| l | r | s[l:r+1] | 条件 | dp[l][r] | 是否更新最优 |
|---|----|-----------|------|----------|-------------|
| 0 | 1 | "ba" | s[0]≠s[1] | False | — |
| 1 | 2 | "ab" | s[1]≠s[2] | False | — |
| 2 | 3 | "ba" | s[2]≠s[3] | False | — |
| 3 | 4 | "ad" | s[3]≠s[4] | False | — |

**i = 2（长度 3 的子串）：**

| l | r | s[l:r+1] | 条件 | dp[l][r] | 是否更新最优 |
|---|----|-----------|------|----------|-------------|
| 0 | 2 | "bab" | dp[1][1]∧s[0]==s[2]=T∧T | **True** | ✅ 更新 (0,2)，len=3 |
| 1 | 3 | "aba" | dp[2][2]∧s[1]==s[3]=T∧T | **True** | ❌ len=3 ≤ 当前最优 3 |
| 2 | 4 | "bad" | dp[3][3]∧s[2]==s[4]=T∧F | False | — |

**i = 3（长度 4 的子串）：**

| l | r | s[l:r+1] | 条件 | dp[l][r] |
|---|----|-----------|------|----------|
| 0 | 3 | "baba" | dp[1][2]∧s[0]==s[3]=F | False |
| 1 | 4 | "abad" | dp[2][3]∧s[1]==s[4]=F | False |

**i = 4（长度 5 的子串）：**

| l | r | s[l:r+1] | 条件 | dp[l][r] |
|---|----|-----------|------|----------|
| 0 | 4 | "babad" | dp[1][3]∧s[0]==s[4]=F∧F | False |

返回 `s[0:3] = "bab"`。（`"aba"` 也是有效答案，代码因使用严格 `>` 比较而保留先找到的。）

### 5. 解法对比：DP vs 中心扩展 vs Manacher

| 对比维度 | 动态规划（本题代码） | 中心扩展法 | Manacher 算法 |
|---------|-----------------|-----------|--------------|
| 时间复杂度 | $O(n^2)$ | $O(n^2)$ | **$O(n)$** |
| 空间复杂度 | $O(n^2)$ | **$O(1)$** | $O(n)$ |
| 实现难度 | 中等 | **简单** | 困难 |
| 核心思想 | 区间 DP 按长度递推 | 以每个位置为中心向两侧扩展 | 利用回文对称性加速 |
| 适用场景 | 学习区间 DP 思维 | **面试推荐**，代码最简洁 | 竞赛/对性能极致要求 |

**中心扩展法**是本题的面试首选解法，只需 $O(n^2)$ 时间和 $O(1)$ 空间：

```python
def longestPalindrome(self, s: str) -> str:
    n, start, max_len = len(s), 0, 1
    for i in range(n):
        # 奇数长度中心
        l, r = i, i
        while l >= 0 and r < n and s[l] == s[r]:
            if r - l + 1 > max_len:
                start, max_len = l, r - l + 1
            l -= 1; r += 1
        # 偶数长度中心
        l, r = i, i + 1
        while l >= 0 and r < n and s[l] == s[r]:
            if r - l + 1 > max_len:
                start, max_len = l, r - l + 1
            l -= 1; r += 1
    return s[start:start + max_len]
```

**DP 解法**虽然空间更大，但其区间 DP 的递推模式（按长度递增、利用内部子问题）是解决一系列回文/区间问题的通用框架，如 [516. 最长回文子序列](https://leetcode.cn/problems/longest-palindromic-subsequence/)、[647. 回文子串](https://leetcode.cn/problems/palindromic-substrings/) 等。

### 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。外层循环 $O(n)$ 个长度，内层循环共约 $\frac{n^2}{2}$ 次迭代，每次 $O(1)$ 操作。

- **空间复杂度**：$O(n^2)$，二维 DP 矩阵。可优化为仅保存最近两个长度的状态，降至 $O(n)$，但会丧失可读性。
