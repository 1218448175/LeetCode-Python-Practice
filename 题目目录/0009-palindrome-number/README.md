## [9. 回文数](https://leetcode.cn/problems/palindrome-number/)

### 简单

<p>给你一个整数 <code>x</code> ，如果 <code>x</code> 是一个回文整数，返回 <code>true</code> ；否则，返回 <code>false</code> 。</p>
<p><strong>回文数</strong>是指正序（从左向右）和倒序（从右向左）读都是一样的整数。</p>
<ul>
	<li>例如，<code>121</code> 是回文，而 <code>123</code> 不是。</li>
</ul>
<p> </p>
<p><strong>示例 1：</strong></p>
<pre><strong>输入：</strong>x = 121
<strong>输出：</strong>true
</pre>
<p><strong>示例 2：</strong></p>
<pre><strong>输入：</strong>x = -121
<strong>输出：</strong>false
<strong>解释：</strong>从左向右读, 为 -121 。 从右向左读, 为 121- 。因此它不是一个回文数。
</pre>
<p><strong>示例 3：</strong></p>
<pre><strong>输入：</strong>x = 10
<strong>输出：</strong>false
<strong>解释：</strong>从右向左读, 为 01 。因此它不是一个回文数。
</pre>
<p> </p>
<p><strong>提示：</strong></p>
<ul>
	<li><code>-2<sup>31</sup> &lt;= x &lt;= 2<sup>31</sup> - 1</code></li>
</ul>
<p> </p>
<p><strong>进阶：</strong>你能不将整数转为字符串来解决这个问题吗？</p>

---

## 题解：字符串对称比较

### 1. 核心思路：字符串化 + 首尾对称比对

回文数的本质是**对称性**：从左到右和从右到左读起来完全一致。你的代码将问题转化为字符串处理，利用 Python 字符串切片的简洁性，实现了一次遍历的首尾对称比对。

核心策略是：
- **整数转字符串**：将数字 `x` 转换为字符串，便于按位访问每一位数字。
- **首尾同时遍历**：同时从头和尾开始遍历，逐位比对是否一致。
- **失配即停**：一旦发现不对称的位置，立即返回 `False`。

### 2. 代码逻辑拆解

- **字符串化**：
  
  使用 `str(x)` 将整数转为字符串，例如 `121` → `"121"`。

- **反向字符串**：
  
  通过 `str(x)[::-1]` 获取反转后的字符串，例如 `"121"` → `"121"`。切片语法 `[::-1]` 以步长 `-1` 遍历，相当于原地反转。

- **并行遍历比对**：
  
  使用 `zip(str(x), str(x)[::-1])` 将正序和反序字符串的字符一一配对：
  - 对于 `121`：配对为 `('1','1')`, `('2','2')`, `('1','1')`
  - 对于 `123`：配对为 `('1','3')`, `('2','2')`, `('3','1')`
  
  在 `for` 循环中对每一对字符进行比较，`a != b` 时立即返回 `False`。

- **最终判定**：
  
  如果循环顺利结束（所有配对都匹配），说明整数是回文数，返回 `True`。

### 3. 复杂度分析

- **时间复杂度：$O(\log_{10} n)$**
  
  - 将整数转为字符串需要遍历每一位数字，数字 `x` 的位数约为 $\log_{10} x$，耗时 $O(\log_{10} n)$。
  - 反转字符串同样需要 $O(\log_{10} n)$。
  - `zip` 并行遍历最多比较 $\log_{10} n$ 对字符，耗时 $O(\log_{10} n)$。
  - 整体时间复杂度与数字的十进制位数成线性关系。

- **空间复杂度：$O(\log_{10} n)$**
  
  - 创建了两个字符串（正序和反序），各占用 $O(\log_{10} n)$ 的空间。
  - `zip` 和迭代器本身占用常数级额外空间。

### 4. 延伸思考

- **进阶解法（不转字符串）**：题目进阶要求不将整数转为字符串。可以通过数学方法**反转一半数字**来实现：
  - 特殊情况处理：负数直接返回 `False`；末尾为 0 的非零数（如 `10`）也返回 `False`。
  - 逐位取余构建反转数 `rev`，同时将原数 `x` 不断除以 10。
  - 当 `x <= rev` 时停止（说明已反转了一半或超过一半的位数）。
  - 最终判断：偶数位时 `x == rev`，奇数位时 `x == rev // 10`（去掉中间那位）。
  - 该解法时间复杂度 $O(\log_{10} n)$，空间复杂度 $O(1)$。

- **对比 125 题（验证回文串）**：125 题需要先过滤非字母数字字符并统一大小写，本题输入已是纯数字，处理更直接。两题的核心思路都是"首尾对称验证"，可互相参照。
