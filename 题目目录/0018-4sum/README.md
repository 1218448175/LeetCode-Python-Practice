## [18. 四数之和](https://leetcode.cn/problems/4sum/)

### 中等

给你一个由 `n` 个整数组成的数组 `nums`，和一个目标值 `target`。请你找出并返回满足下述全部条件且**不重复**的四元组 `[nums[a], nums[b], nums[c], nums[d]]`（若两个四元组元素一一对应，则认为两个四元组重复）：

- `0 <= a, b, c, d < n`
- `a`、`b`、`c` 和 `d` **互不相同**
- `nums[a] + nums[b] + nums[c] + nums[d] == target`

你可以按**任意顺序**返回答案。

**示例 1：**
<pre><strong>输入：</strong>nums = [1, 0, -1, 0, -2, 2], target = 0
<strong>输出：</strong>[[-2, -1, 1, 2], [-2, 0, 0, 2], [-1, 0, 0, 1]]
</pre>

**示例 2：**
<pre><strong>输入：</strong>nums = [2, 2, 2, 2, 2], target = 8
<strong>输出：</strong>[[2, 2, 2, 2]]
</pre>

---

## 题解：排序 + 双层循环 + 双指针 + 剪枝优化

### 1. 核心思路

本题是 [15. 三数之和](https://leetcode.cn/problems/3sum/) 的直接推广。在三数之和的基础上，再多加一层循环固定第二个数，将四数问题转化为三数子问题，再用双指针解决后两数。

核心策略：

- **排序为基石**：先对数组升序排列，便于去重、双指针方向控制以及后续的剪枝优化。
- **双层循环固定前两数**：外层枚举 `a`（第一个数），内层枚举 `b`（第二个数）。
- **双指针夹逼后两数**：在 `b+1` 到 `n-1` 范围内，使用 `c`（左指针）和 `d`（右指针）寻找剩余两数。
- **去重贯穿全程**：每一层（`a`、`b`、`c`、`d`）均需跳过重复元素。

---

### 2. 逻辑亮点：两处剪枝优化

代码相较于标准解法增加了两处关键剪枝，大幅减少无效搜索：

#### A. 最小值剪枝（`break`）

在固定 `a` 后，若**当前所能取到的最小四数和**已经大于 `target`，则后续更大的 `a` 只会使和更大，直接 `break` 终止外层循环：

```python
if x + nums[a + 1] + nums[a + 2] + nums[a + 3] > target:
    break
```

同理，在固定 `a` 和 `b` 后：

```python
if x + y + nums[b + 1] + nums[b + 2] > target:
    break
```

#### B. 最大值剪枝（`continue`）

在固定 `a` 后，若**当前所能取到的最大四数和**仍然小于 `target`，说明这个 `a` 太小，直接 `continue` 尝试更大的 `a`：

```python
if x + nums[-3] + nums[-2] + nums[-1] < target:
    continue
```

同理，在固定 `a` 和 `b` 后：

```python
if x + y + nums[-2] + nums[-1] < target:
    continue
```

这两处剪枝在实际数据中能显著减少进入双指针阶段的次数，是性能优化的关键。

---

### 3. 双指针的同步演进

对于每一组固定的 `(a, b)`，`c` 从 `b+1` 向右移动，`d` 从 `n-1` 向左移动：

- `s == target` → 记录结果，`c` 右移（跳过重复）、`d` 左移（跳过重复）
- `s > target` → `d` 左移（减小和）
- `s < target` → `c` 右移（增大和）

由于排序保证了单调性，双指针的移动方向与和的大小关系严格对应，整个内层搜索可以在 $O(N)$ 时间内完成。

---

### 4. 复杂度分析

- **时间复杂度**：$O(N^3)$。
  - 排序耗时 $O(N \log N)$。
  - 外层两层循环 $O(N^2)$，内层双指针 $O(N)$，综合 $O(N^3)$。
  - 剪枝优化在多数情况下能显著降低实际运行时间，但最坏复杂度不变。

- **空间复杂度**：$O(\log N)$。
  - 主要为排序所需的额外栈空间，不计结果数组。

---

### 延伸思考

- 本题与 [15. 三数之和](https://leetcode.cn/problems/3sum/) 一脉相承，掌握"排序 + 双指针"的套路后，任意 N 数之和都可依此模式求解。
- 剪枝优化的思想在回溯/搜索类问题中广泛应用——通过极值预判提前阻断无效分支。
- 若数组包含大量重复元素，去重逻辑是否正确直接影响结果正确性，需特别关注每一层的跳过条件（`a` 层用 `nums[a] == nums[a-1]`，`b` 层用 `b > a+1 and nums[b] == nums[b-1]`）。
