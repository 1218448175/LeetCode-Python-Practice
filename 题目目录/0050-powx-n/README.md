## [50. Pow(x, n)](https://leetcode.cn/problems/powx-n/)

### 中等

<p>实现 <a href="https://www.cplusplus.com/reference/valarray/pow/" target="_blank">pow(x, n)</a> ，即计算 <code>x</code> 的整数 <code>n</code> 次幂函数（即 <code>x<sup>n</sup></code>）。</p>
<p> </p>
<p><strong>示例 1：</strong></p>
<pre><strong>输入：</strong>x = 2.00000, n = 10
<strong>输出：</strong>1024.00000
</pre>
<p><strong>示例 2：</strong></p>
<pre><strong>输入：</strong>x = 2.10000, n = 3
<strong>输出：</strong>9.26100
</pre>
<p><strong>示例 3：</strong></p>
<pre><strong>输入：</strong>x = 2.00000, n = -2
<strong>输出：</strong>0.25000
<strong>解释：</strong>2<sup>-2</sup> = 1/2<sup>2</sup> = 1/4 = 0.25
</pre>
<p> </p>
<p><strong>提示：</strong></p>
<ul>
	<li><code>-100.0 &lt; x &lt; 100.0</code></li>
	<li><code>-2<sup>31</sup> &lt;= n &lt;= 2<sup>31</sup> - 1</code></li>
	<li><code>n</code> 是一个 32 位有符号整数</li>
	<li><code>-10<sup>4</sup> &lt;= x<sup>n</sup> &lt;= 10<sup>4</sup></code></li>
</ul>

---

## 题解：快速幂（二进制指数拆分 / 迭代）

### 1. 核心思路：将指数按二进制位拆分，逐位累乘

暴力做法是将 $x$ 自乘 $n$ 次，时间复杂度 $O(n)$，在 $n$ 高达 $2^{31} - 1$ 时会超时。

快速幂的核心思想是**二进制拆分**：任何一个正整数 $n$ 都可以表示为二进制，例如 $n = 11 = 1011_2$：

$$x^{11} = x^{8 + 2 + 1} = x^8 \cdot x^2 \cdot x^1$$

算法从低位到高位遍历 $n$ 的二进制位，同时维护一个"贡献值" $x_{contribute}$，对应每一位的权重：
- **初始**：$x_{contribute} = x$（对应二进制第 0 位，权重 $x^1$）
- **每右移一位**：$x_{contribute}$ 自乘，权重翻倍（$x^1 \to x^2 \to x^4 \to x^8 \to \dots$）
- **当前位为 1 时**：将此时的 $x_{contribute}$ 乘入答案

当 $n < 0$ 时，计算 $x^n = 1 / x^{-n}$。

### 2. 代码逻辑拆解

- **负数指数处理**：
  
  标记 `d = -1`，将 `n` 取反变为正数。最终若 `d == -1`，返回 `1 / ans`。

- **快速幂循环**：
  
  - `x_contribute = x`：初始贡献值为 $x$
  - `while n > 0`：遍历 $n$ 的二进制位
  - `if n % 2 == 1`：当前最低位为 1，将贡献值乘入答案
  - `x_contribute *= x_contribute`：贡献值翻倍（$x^1 \to x^2 \to x^4 \to \dots$）
  - `n //= 2`：右移一位

- **返回结果**：
  
  - 若 `d == 1`（原指数为正），直接返回 `ans`
  - 若 `d == -1`（原指数为负），返回 `1 / ans`

### 3. 举例推演

以 $x = 2.0,\ n = 11$ 为例（$n$ 的二进制为 $1011$）：

| 步骤 | n | n % 2 | ans | x_contribute | 操作 |
|------|---|-------|-----|-------------|------|
| 初始 | 11 | - | 1 | 2.0 ($x^1$) | - |
| 1 | 11 | 1 | 2.0 | 4.0 ($x^2$) | ans ×= 2.0, n //= 2 |
| 2 | 5 | 1 | 8.0 | 16.0 ($x^4$) | ans ×= 4.0, n //= 2 |
| 3 | 2 | 0 | 8.0 | 256.0 ($x^8$) | ans 不变, n //= 2 |
| 4 | 1 | 1 | 2048.0 | 65536.0 ($x^{16}$) | ans ×= 256.0, n //= 2 |
| 结束 | 0 | - | 2048.0 | - | 循环结束 |

结果：$2^{11} = 2048.0$。验证：$2^1 \cdot 2^2 \cdot 2^8 = 2 \cdot 4 \cdot 256 = 2048$。

以 $x = 2.0,\ n = -2$ 为例：

| 步骤 | n | n % 2 | ans | x_contribute | 操作 |
|------|---|-------|-----|-------------|------|
| 初始 | 2 | - | 1 | 2.0 ($x^1$) | d = -1, n = 2 |
| 1 | 2 | 0 | 1 | 4.0 ($x^2$) | ans 不变, n //= 2 |
| 2 | 1 | 1 | 4.0 | 16.0 ($x^4$) | ans ×= 4.0, n //= 2 |
| 结束 | 0 | - | 4.0 | - | 循环结束 |

$d = -1$，返回 $1 / 4.0 = 0.25$。验证：$2^{-2} = 1 / 4 = 0.25$。

### 4. 复杂度分析

- **时间复杂度：$O(\log n)$**
  
  每次循环将 $n$ 右移一位（折半），最多进行 $\log_2 n$ 次迭代。对于 $n \le 2^{31} - 1$，最多 31 次迭代。

- **空间复杂度：$O(1)$**
  
  仅使用常数级变量 `ans`、`x_contribute`、`d`、`n`。

### 5. 延伸思考

- **递归实现**：快速幂同样可以用递归实现，思路是 $x^n = (x^{n/2})^2$（$n$ 为偶数）或 $x^n = x \cdot (x^{n/2})^2$（$n$ 为奇数）。递归写法更直观，但迭代实现避免了递归调用栈开销，常数更优。

- **负数边界问题**：当 $n = -2147483648$（$-2^{31}$，即 `INT_MIN`）时，直接取反 `n = -n` 会导致 32 位有符号整数溢出。题解代码先将 `n *= -1`，在 Python 中无此问题（Python 整数无限大），但若用 C++/Java 等语言实现，需先转为 `long` 类型再取反。

- **对比 69 题（x 的平方根）**：69 题使用二分查找求平方根，本质上也是指数运算的特例（$x^{0.5}$）。而本题的快速幂算法是更通用的指数运算方法，适用于任意整数指数。
