## [52. N 皇后 II](https://leetcode.cn/problems/n-queens-ii/)

### 困难

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n × n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n` ，返回 **n 皇后问题** 不同的解决方案的数量。

**示例 1：**

```
输入：n = 4
输出：2
解释：如上图所示，4 皇后问题存在两个不同的解法。
```

**示例 2：**

```
输入：n = 1
输出：1
```

---

## 题解：回溯 + 位运算压状态

### 1. 核心思路：按行放皇后，用三个掩码记录占用

- 与 [51. N 皇后](https://leetcode.cn/problems/n-queens/) 输出所有棋盘不同，本题只统计 **方案数**，不必构造棋盘。
- 逐行放置：第 `row` 行在某一列放皇后后，下一行可选列必须满足：
  - 该列未被占用（`cols`）；
  - 不在左斜线 `ld`、右斜线 `rd` 上（随深度左移 / 右移更新）。
- 用长度为 `n` 的 **位掩码** 表示列与斜线占用：`1` 表示不可放，`0` 表示可放。
- `done = (1 << n) - 1`：低 `n` 位全为 `1`，表示「`n` 列都已放满」；当 `cols == done` 时，说明 `n` 行各放了一枚皇后，方案数 `+1`。

---

### 2. 当前行可选位置

```text
pos = done & (~(cols | ld | rd))
```

- `cols | ld | rd`：列、两条斜线上所有禁放位；
- 取反后高位会出现大量 `1`，用 `done` 截断，只保留低 `n` 位中的 **可放列**。

枚举 `pos` 中每一个 `1`（从低到高）：

1. `p = pos & -pos`：取出最低位的 `1`（即本行尝试的列）；
2. `pos -= p`：去掉该候选；
3. 递归下一行：
   - `cols | p`：该列已占；
   - `(ld | p) << 1`：左斜线向下一行左移一位；
   - `(rd | p) >> 1`：右斜线向下一行右移一位。

各分支返回值累加即为总方案数。

---

### 3. 与「逐格 DFS + used 数组」的对比

| 写法 | 优点 |
|------|------|
| `used` 列 + 两条斜线数组 | 直观，易理解 |
| 位掩码 | 状态三个整数，判冲突与枚举都是 O(1) 位运算，常数小 |

思路与标准回溯相同，只是把「列 / 斜线是否占用」压缩进整数。

---

### 4. 复杂度分析

- **时间复杂度**：最坏需遍历所有合法放法，约为 $O(n!)$ 量级（带剪枝的实际远小于 $n^n$）。
- **空间复杂度**：$O(n)$ 递归深度；无额外数组存棋盘。

---

### 5. 代码回顾

```python
class Solution:
    def totalNQueens(self, n: int) -> int:
        done = (1 << n) - 1

        def backtrack(cols, ld, rd) -> int:
            if cols == done:
                return 1
            count = 0
            pos = done & (~(cols | ld | rd))
            while pos:
                p = pos & -pos
                pos -= p
                count += backtrack(cols | p, (ld | p) << 1, (rd | p) >> 1)
            return count

        return backtrack(0, 0, 0)
```

`pos & -pos` 是经典技巧，用于快速枚举集合中的每一个可选下标（此处为列号）。
