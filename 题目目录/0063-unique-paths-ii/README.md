## [63. 不同路径 II](https://leetcode.cn/problems/unique-paths-ii/)

### 中等

给定一个 `m × n` 的整数数组 `grid`。一个机器人初始位于**左上角**（即 `grid[0][0]`）。机器人尝试移动到**右下角**（即 `grid[m-1][n-1]`）。机器人每次只能向下或者向右移动一步。

网格中的障碍物和空位置分别用 `1` 和 `0` 来表示。机器人的移动路径中不能包含**任何**有障碍物的方格。

返回机器人能够到达右下角的不同路径数量。题目数据保证答案小于等于 `2 × 10⁹`。

<p><strong>示例 1:</strong></p>
<pre><strong>输入:</strong> obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]
<strong>输出:</strong> 2
<strong>解释:</strong> 3×3 网格的正中间有一个障碍物。
从左上角到右下角一共有 2 条不同的路径：
1. 向右 → 向右 → 向下 → 向下
2. 向下 → 向下 → 向右 → 向右
</pre>

<p><strong>示例 2:</strong></p>
<pre><strong>输入:</strong> obstacleGrid = [[0,1],[0,0]]
<strong>输出:</strong> 1
</pre>

---

## 题解：动态规划 — 滚动数组 + 障碍物判断

### 1. 核心思路：在 62 题基础上增加障碍物处理

本题是 [62. 不同路径](https://leetcode.cn/problems/unique-paths/) 的进阶版，唯一区别是网格中可能存在障碍物。核心递推公式不变：

$$dp[i][j] = dp[i-1][j] + dp[i][j-1]$$

关键变化在于障碍物处理：
- 若 `obstacleGrid[i][j] == 1`（障碍物），则该格子不可达，`dp[i][j] = 0`
- 起点或终点若为障碍物，直接返回 0

---

### 2. 代码设计：一维滚动数组 + 合循环

本题代码使用**一维滚动数组** `dp` 进行空间优化，并将初始化、首行/首列边界、内部递推全部合并到**一个双层循环**中：

```python
dp = [1 if i == 0 else 0 for i in obstacleGrid[0]]
```

初始化逻辑解读：
- 遍历第一行的每个值 `i`（`i` 为 `obstacleGrid[0][j]` 的实际值，即 0 或 1）
- 若 `i == 0`（空地），`dp[j] = 1`
- 若 `i == 1`（障碍物），`dp[j] = 0`
- 若 `dp[0] == 0`（起点有障碍物），直接返回 0

循环中的四种分支：

| 位置 | 条件 | 处理逻辑 |
|------|------|----------|
| 起点 | `i==0, j==0` | `continue`，保留初始值 |
| 首列（非首行） | `i!=0, j==0` | `dp[0] = 0` 若遇障碍物，否则保留 `dp[0]`（上一行的值向下传播） |
| 首行（非首列） | `i==0, j!=0` | `dp[j] = 0` 若遇障碍物，否则 `dp[j] = dp[j-1]`（左侧值向右传播） |
| 内部格子 | `else` | `dp[j] = 0` 若遇障碍物，否则 `dp[j] = dp[j] + dp[j-1]`（上 + 左） |

其中 `dp[j]` 在更新前保存的是上一行同列的值（即 `dp[i-1][j]`），`dp[j-1]` 已更新为当前行左侧的值（即 `dp[i][j-1]`），因此 `dp[j] + dp[j-1]` 等价于标准公式 `dp[i-1][j] + dp[i][j-1]`。

---

### 3. 变量设计与迭代推演

| 变量 | 含义 | 初始值 |
|------|------|--------|
| `m` | 网格行数 | `len(obstacleGrid)` |
| `n` | 网格列数 | `len(obstacleGrid[0])` |
| `dp` | 一维滚动数组，长度为 n | 见初始化逻辑 |

以 `obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]` 为例的推演过程：

**初始化：** `dp = [1, 1, 1]`（第一行均为空地），`dp[0] = 1 ≠ 0`，继续。

**i = 0（首行）：**

| j | grid[0][j] | 分支 | 计算 | dp |
|---|-----------|------|------|-----|
| 0 | 0 | continue | — | [1, 1, 1] |
| 1 | 0 | 首行非首列 | `dp[1] = dp[0] = 1` | [1, 1, 1] |
| 2 | 0 | 首行非首列 | `dp[2] = dp[1] = 1` | [1, 1, 1] |

**i = 1（第二行）：**

| j | grid[1][j] | 分支 | 计算 | dp |
|---|-----------|------|------|-----|
| 0 | 0 | 首列非首行 | `dp[0] = dp[0] = 1` | [1, 1, 1] |
| 1 | **1**（障碍） | 内部 | `dp[1] = 0` | [1, **0**, 1] |
| 2 | 0 | 内部 | `dp[2] = dp[2] + dp[1] = 1 + 0 = 1` | [1, 0, **1**] |

**i = 2（第三行）：**

| j | grid[2][j] | 分支 | 计算 | dp |
|---|-----------|------|------|-----|
| 0 | 0 | 首列非首行 | `dp[0] = dp[0] = 1` | [1, 0, 1] |
| 1 | 0 | 内部 | `dp[1] = dp[1] + dp[0] = 0 + 1 = 1` | [1, **1**, 1] |
| 2 | 0 | 内部 | `dp[2] = dp[2] + dp[1] = 1 + 1 = 2` | [1, 1, **2**] |

返回 `dp[-1] = 2`。✅

---

### 4. 障碍物阻断传播的机制

首行和首列的障碍物处理是本代码的一个精妙之处。以首行为例：

```
obstacleGrid[0] = [0, 1, 0]
初始化: dp = [1, 0, 1]

i=0, j=1: dp[1] = 0 (障碍物)    → dp = [1, 0, 1]
i=0, j=2: dp[2] = dp[1] = 0    → dp = [1, 0, 0]  ← 障碍物之后的格子自动归零！
```

因为 `dp[j] = dp[j-1]` 的传播机制，障碍物 `dp[1] = 0` 会"传染"给其右侧所有格子。首列同理，`dp[0]` 一旦变为 0，该列以下所有行均不可达。

---

### 5. 与 62 题和 64 题的对比

| 对比维度 | 62. 不同路径 | **63. 不同路径 II** | 64. 最小路径和 |
|---------|------------|-------------------|---------------|
| 障碍物 | 无 | **有（1 为障碍）** | 无 |
| DP 类型 | 计数累加 | **计数累加 + 障碍清零** | 最优化取最小 |
| 递推公式 | $dp[i][j]=dp[i-1][j]+dp[i][j-1]$ | 同上，障碍处为 0 | $dp[i][j]=\min(上,左)+g[i][j]$ |
| 首行/列传播 | 全为 1 | **遇障碍后全为 0** | 累加前缀和 |
| 空间优化 | $O(n)$ | $O(n)$ | $O(n)$ |
| 是否可以原地 DP | ✅ | ✅（需区分 0/1） | ✅ |

三道题构成经典的"网格路径 DP 三部曲"，从计数到带障碍再到带权最优化，层层递进。

---

### 6. 复杂度分析

- **时间复杂度**：$O(m \times n)$，每个格子访问一次。

- **空间复杂度**：$O(n)$，一维滚动数组。相比二维 DP 的 $O(m \times n)$，空间节省显著。
