## [64. 最小路径和](https://leetcode.cn/problems/minimum-path-sum/)

### 中等

给定一个包含非负整数的 `m × n` 网格 `grid`，请找出一条从左上角到右下角的路径，使得路径上的数字总和最小。

**说明：** 每次只能向下或者向右移动一步。

<p><strong>示例 1:</strong></p>
<pre><strong>输入:</strong> grid = [[1,3,1],[1,5,1],[4,2,1]]
<strong>输出:</strong> 7
<strong>解释:</strong> 因为路径 1→3→1→1→1 的总和最小。
</pre>

<p><strong>示例 2:</strong></p>
<pre><strong>输入:</strong> grid = [[1,2,3],[4,5,6]]
<strong>输出:</strong> 12
</pre>

---

## 题解：动态规划 — 二维网格递推

### 1. 核心思路：到达每个格子的最小代价

这道题是经典的二维网格 DP，与 [62. 不同路径](https://leetcode.cn/problems/unique-paths/) 一脉相承，区别在于把"路径计数"换成了"路径和取最小"。

定义 `dp[i][j]` 表示从左上角 `(0, 0)` 走到 `(i, j)` 的最小路径和。

由于只能向右或向下移动，到达 `(i, j)` 只有两种可能：
- 从上方 `(i-1, j)` 向下走一步
- 从左方 `(i, j-1)` 向右走一步

取两者中路径和较小的，加上当前格子的值：

$$dp[i][j] = \min(dp[i-1][j],\ dp[i][j-1]) + grid[i][j]$$

边界情况：
- **首行 `i == 0`**：只能从左边来，`dp[0][j] = dp[0][j-1] + grid[0][j]`
- **首列 `j == 0`**：只能从上方来，`dp[i][0] = dp[i-1][0] + grid[i][0]`
- **起点**：`dp[0][0] = grid[0][0]`

---

### 2. 变量设计与迭代推演

| 变量 | 含义 | 初始值 |
|------|------|--------|
| `m` | 网格行数 | `len(grid)` |
| `n` | 网格列数 | `len(grid[0])` |
| `dp` | 二维 DP 数组，`dp[i][j]` 表示到 `(i, j)` 的最小路径和 | 全零 `m×n` 矩阵 |

以 `grid = [[1,3,1],[1,5,1],[4,2,1]]` 为例的推演过程：

**初始化：**

| dp | 列 0 | 列 1 | 列 2 |
|----|------|------|------|
| 行 0 | **1** | 4 | 5 |
| 行 1 | 2 | · | · |
| 行 2 | 6 | · | · |

- `dp[0][0] = grid[0][0] = 1`
- 首行：`dp[0][1] = 1 + 3 = 4`，`dp[0][2] = 4 + 1 = 5`
- 首列：`dp[1][0] = 1 + 1 = 2`，`dp[2][0] = 2 + 4 = 6`

**递推填充内部格子：**

| (i,j) | grid[i][j] | 来源 | 计算 | dp[i][j] |
|-------|------------|------|------|----------|
| (1,1) | 5 | min(上4, 左2) | `min(4, 2) + 5` | **7** |
| (1,2) | 1 | min(上5, 左7) | `min(5, 7) + 1` | **6** |
| (2,1) | 2 | min(上7, 左6) | `min(7, 6) + 2` | **8** |
| (2,2) | 1 | min(上6, 左8) | `min(6, 8) + 1` | **7** |

最终 DP 表：

| dp | 列 0 | 列 1 | 列 2 |
|----|------|------|------|
| 行 0 | 1 | 4 | 5 |
| 行 1 | 2 | 7 | 6 |
| 行 2 | 6 | 8 | **7** |

返回 `dp[2][2] = 7`。对应路径 `(0,0)→(1,0)→(1,1)→(1,2)→(2,2)`，即 `1→1→5→1→1 = 7`。

### 3. 代码结构分析

本题代码将初始化和递推合并到一个双层循环中，通过条件分支区分三种情况：

```python
for i in range(m):
    for j in range(n):
        if i == 0 and j != 0:        # 首行：只能从左边来
            dp[i][j] = dp[i][j - 1] + grid[i][j]
        elif j == 0 and i != 0:      # 首列：只能从上方来
            dp[i][j] = dp[i - 1][j] + grid[i][j]
        elif i != 0 and j != 0:      # 内部：取上方和左方的较小值
            dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]
```

`dp[0][0]` 在循环前单独赋值为 `grid[0][0]`，循环中 `i==0, j==0` 时不进入任何分支，保留初始值。

---

### 4. 空间优化：O(n) 一维数组

由于每行只依赖上一行和当前行左侧的值，可以用一维滚动数组替代二维矩阵：

```python
def minPathSum(self, grid: List[List[int]]) -> int:
    m, n = len(grid), len(grid[0])
    dp = [0] * n
    for i in range(m):
        for j in range(n):
            if i == 0 and j == 0:
                dp[j] = grid[i][j]
            elif i == 0:
                dp[j] = dp[j - 1] + grid[i][j]
            elif j == 0:
                dp[j] = dp[j] + grid[i][j]       # dp[j] 本身存的就是上一行的值
            else:
                dp[j] = min(dp[j], dp[j - 1]) + grid[i][j]
    return dp[n - 1]
```

解释：
- `dp[j]` 在处理第 `i` 行时，当前值还是上一行的 `dp[i-1][j]`
- `dp[j-1]` 已经更新为当前行的 `dp[i][j-1]`
- 因此 `min(dp[j], dp[j-1])` 等价于 `min(dp[i-1][j], dp[i][j-1])`

| 对比维度 | 二维 DP（本题代码） | 一维 DP（优化版） |
|---------|-----------------|-------------------|
| 空间复杂度 | $O(m \times n)$ | **$O(n)$** |
| 代码结构 | 三层条件分支，直观易懂 | 复用旧值，需理解滚动含义 |
| 适用场景 | 需要回溯具体路径时 | 只需最优值时 |

若允许修改原数组，可进一步在 `grid` 上原地 DP，达到 $O(1)$ 额外空间。
