## [67. 二进制求和](https://leetcode.cn/problems/add-binary/)

### 简单

给你两个二进制字符串 `a` 和 `b`，以二进制字符串的形式返回它们的和。

**示例 1：**

<pre><strong>输入：</strong>a = "11", b = "1"
<strong>输出：</strong>"100"</pre>

**示例 2：**

<pre><strong>输入：</strong>a = "1010", b = "1011"
<strong>输出：</strong>"10101"</pre>

**提示：**

- `1 <= a.length, b.length <= 10^4`
- `a` 和 `b` 仅由字符 `'0'` 或 `'1'` 组成
- 字符串如果不是 `"0"`，就不含前导零

---

## 题解：双指针模拟竖式加法

### 1. 核心思路：逢二进一

二进制加法与十进制加法的本质完全相同，只是进位规则从"逢十进一"变为"**逢二进一**"。

我们**从两个字符串的末尾开始**，逐位相加，同时维护一个进位变量 `carry`。每一位的计算遵循：

- 当前位和 = `digit_a + digit_b + carry`
- 当前位结果 = `当前位和 % 2`（取余数，即 0 或 1）
- 新进位 = `当前位和 // 2`（整除，即 0 或 1）

最终反转结果列表即可得到从左到右的二进制和字符串。

---

### 2. 执行逻辑的详细拆解

#### A. 初始化

- `ans`：结果列表，用于暂存每一位的计算结果（从低位到高位）
- `i = len(a) - 1`，`j = len(b) - 1`：双指针分别指向两个字符串的末位
- `carry = 0`：进位标志

#### B. 主循环

`while i >= 0 or j >= 0 or carry:` 这个循环条件值得仔细品味：

1. **`i >= 0`**：字符串 `a` 还有未处理的位
2. **`j >= 0`**：字符串 `b` 还有未处理的位
3. **`carry`**：即使两个字符串都已处理完毕，如果还有进位（如 `"1" + "1" = "10"`），仍需要继续追加最高位

#### C. 逐位计算

```python
x = int(a[i]) if i >= 0 else 0   # 取 a 当前位，越界则补 0
y = int(b[j]) if j >= 0 else 0   # 取 b 当前位，越界则补 0
s = x + y + carry                # 当前位总和
ans.append(str(s % 2))           # 结果位：取模 2
carry = s // 2                   # 进位：整除 2
```

#### D. 收尾

`return ''.join(reversed(ans))` —— 因为我们是**从低位向高位**逐位 `append` 的，所以结果列表是逆序的，需要反转后拼接成最终字符串。

---

### 3. 逻辑亮点

- **隐式对齐**：通过 `if i >= 0 else 0` 的方式，天然处理了两个字符串长度不一致的情况，无需预先补零。

- **循环条件包含进位**：避免了循环结束后还要单独判断 `carry == 1` 的场景，代码更加简洁。

- **就地构建**：使用列表 `append` 而非字符串拼接（Python 中字符串不可变，频繁拼接会产生大量临时对象），最后一次性 `join` + `reverse`，效率更优。

---

### 4. 复杂度分析

- **时间复杂度**：$O(\max(m, n))$，其中 $m$ 和 $n$ 分别为两个字符串的长度。每个字符被遍历恰好一次。

- **空间复杂度**：$O(\max(m, n))$，结果列表 `ans` 存储最终和的每一位。不考虑结果所占空间则为 $O(1)$。

---

### 代码回顾

```python
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        ans = []
        i = len(a) - 1
        j = len(b) - 1
        carry = 0
        while i >= 0 or j >= 0 or carry:
            x = int(a[i]) if i >= 0 else 0
            y = int(b[j]) if j >= 0 else 0
            s = x + y + carry
            ans.append(str(s % 2))
            carry = s // 2
            i -= 1
            j -= 1
        return ''.join(reversed(ans))
```

> **延伸思考**：此题也可用**位运算**实现——将两个字符串转为整数后，利用 `x ^ y` 求无进位和、`(x & y) << 1` 求进位，迭代至进位为 0。但 Python 的 `int(a, 2)` 方式本质上依赖语言内建的大数转换，在面试中通常不被视为算法解，且可能在大输入时溢出（其他语言）。**模拟竖式加法**是最通用、最能体现算法思维的做法。
