## [72. 编辑距离](https://leetcode.cn/problems/edit-distance/)

### 困难

给你两个单词 `word1` 和 `word2`，请返回将 `word1` 转换成 `word2` 所使用的最少操作数。

你可以对一个单词进行如下三种操作：
- 插入一个字符
- 删除一个字符
- 替换一个字符

<p><strong>示例 1:</strong></p>
<pre><strong>输入:</strong> word1 = "horse", word2 = "ros"
<strong>输出:</strong> 3
<strong>解释:</strong>
horse → rorse (将 'h' 替换为 'r')
rorse → rose  (删除 'r')
rose  → ros   (删除 'e')
</pre>

<p><strong>示例 2:</strong></p>
<pre><strong>输入:</strong> word1 = "intention", word2 = "execution"
<strong>输出:</strong> 5
<strong>解释:</strong>
intention → inention  (删除 't')
inention  → enention  (将 'i' 替换为 'e')
enention  → exention  (将 'n' 替换为 'x')
exention  → exection  (将 'n' 替换为 'c')
exection  → execution (插入 'u')
</pre>

## 题解：动态规划 — 莱文斯坦距离

### 1. 核心思路：三种操作对应三个子问题

这道题是经典的**编辑距离**（Levenshtein Distance）问题。定义 `dp[i][j]` 表示将 `word1` 的前 `i` 个字符转换为 `word2` 的前 `j` 个字符所需的最少操作数。

当 `word1[i-1]` 与 `word2[j-1]` 不同时，有三种方式完成转换，对应三种操作：

| 操作 | 含义 | 子问题 | 转移公式 |
|------|------|--------|---------|
| **删除** | 删掉 `word1[i-1]`，用前 `i-1` 个字符匹配 `j` 个字符 | `dp[i-1][j]` | `dp[i-1][j] + 1` |
| **插入** | 在 `word1` 末尾插入 `word2[j-1]`，用 `i` 个字符匹配前 `j-1` 个字符 | `dp[i][j-1]` | `dp[i][j-1] + 1` |
| **替换** | 将 `word1[i-1]` 改成 `word2[j-1]`，用前 `i-1` 个字符匹配前 `j-1` 个字符 | `dp[i-1][j-1]` | `dp[i-1][j-1] + 1` |

当字符相同时，无需额外操作：

$$dp[i][j] = dp[i-1][j-1] \quad \text{(字符相同，免费继承)}$$

由此得到完整的状态转移方程：

$$dp[i][j] =
\begin{cases}
j, & i = 0 \quad \text{(空串 → word2 前缀：全插入)} \\[4pt]
i, & j = 0 \quad \text{(word1 前缀 → 空串：全删除)} \\[4pt]
dp[i-1][j-1], & word_1[i-1] = word_2[j-1] \\[4pt]
\min(dp[i-1][j],\ dp[i][j-1],\ dp[i-1][j-1]) + 1, & word_1[i-1] \neq word_2[j-1]
\end{cases}$$

**记忆口诀：相等抄左上，不等取最小（左上/上/左）+ 1。**

### 2. 变量设计与迭代推演

| 变量 | 含义 | 初始值 |
|------|------|--------|
| `m, n` | `word1` 和 `word2` 的长度 | `len(word1)`, `len(word2)` |
| `dp` | `(m+1) × (n+1)` 整数矩阵 | 全零 |

以 `word1 = "horse"`, `word2 = "ros"` 为例推演：

**初始化首行/首列：**

| dp | j=0 | j=1(r) | j=2(o) | j=3(s) |
|----|-----|--------|--------|--------|
| i=0 | **0** | 1 | 2 | 3 |
| i=1(h) | 1 | · | · | · |
| i=2(o) | 2 | · | · | · |
| i=3(r) | 3 | · | · | · |
| i=4(s) | 4 | · | · | · |
| i=5(e) | 5 | · | · | · |

**递推过程：**

| i | j | w1[i-1] | w2[j-1] | 字符？ | 三种操作值 | dp[i][j] |
|---|----|---------|---------|--------|-----------|----------|
| 1 | 1 | h | r | ≠ | `min(1,1,0)+1` | **1** 替换 |
| 1 | 2 | h | o | ≠ | `min(1,2,1)+1` | **2** 替换 |
| 1 | 3 | h | s | ≠ | `min(1,3,2)+1` | **2** 替换 |
| 2 | 1 | o | r | ≠ | `min(2,1,1)+1` | **2** 替换 |
| 2 | 2 | o | o | = | `dp[1][1]` | **1** 抄左上 |
| 2 | 3 | o | s | ≠ | `min(2,2,1)+1` | **2** 替换 |
| 3 | 1 | r | r | = | `dp[2][0]` | **2** 抄左上 |
| 3 | 2 | r | o | ≠ | `min(2,2,1)+1` | **2** 替换 |
| 3 | 3 | r | s | ≠ | `min(2,3,2)+1` | **3** 替换 |
| 4 | 1 | s | r | ≠ | `min(3,3,2)+1` | **3** 替换 |
| 4 | 2 | s | o | ≠ | `min(3,3,2)+1` | **3** 替换 |
| 4 | 3 | s | s | = | `dp[3][2]` | **2** 抄左上 |
| 5 | 1 | e | r | ≠ | `min(4,4,3)+1` | **4** 替换 |
| 5 | 2 | e | o | ≠ | `min(4,4,3)+1` | **4** 替换 |
| 5 | 3 | e | s | ≠ | `min(4,4,2)+1` | **3** 插入 |

最终 DP 表：

| dp | j=0 | j=1(r) | j=2(o) | j=3(s) |
|----|-----|--------|--------|--------|
| i=0 | 0 | 1 | 2 | 3 |
| i=1(h) | 1 | 1 | 2 | 2 |
| i=2(o) | 2 | 2 | 1 | 2 |
| i=3(r) | 3 | 2 | 2 | 3 |
| i=4(s) | 4 | 3 | 3 | 2 |
| i=5(e) | 5 | 4 | 4 | **3** |

返回 `dp[5][3] = 3`。✅

### 3. 代码结构分析

本题代码同样使用**合循环**方式处理首行/首列/内部格子：

```python
for i in range(m + 1):
    for j in range(n + 1):
        if i == 0:
            dp[i][j] = j          # 空串 → word2[0:j]：全插入
        elif j == 0:
            dp[i][j] = i          # word1[0:i] → 空串：全删除
        else:
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]     # 字符相同，免费继承
            else:
                dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
```

首行/首列的边界值 `i` 和 `j` 有明确的语义：
- `dp[0][j] = j`：将空串变为长度为 `j` 的字符串，需要 `j` 次插入
- `dp[i][0] = i`：将长度为 `i` 的字符串变为空串，需要 `i` 次删除

### 4. 空间优化：O(n) 一维数组

由于 `dp[i][j]` 只依赖上一行和当前行左侧的值，可以优化为 O(n)：

```python
def minDistance(self, word1: str, word2: str) -> int:
    m, n = len(word1), len(word2)
    dp = list(range(n + 1))       # 初始化为 dp[0][j] = j

    for i in range(1, m + 1):
        prev = dp[0]              # 保存左上角 dp[i-1][j-1]
        dp[0] = i                 # dp[i][0] = i
        for j in range(1, n + 1):
            temp = dp[j]          # 暂存当前 dp[j]，下一轮作为左上角
            if word1[i - 1] == word2[j - 1]:
                dp[j] = prev
            else:
                dp[j] = min(dp[j], dp[j - 1], prev) + 1
            prev = temp           # 更新左上角
    return dp[n]
```

滚动数组的关键在于用 `prev` 变量保存"左上角"的值 `dp[i-1][j-1]`，因为 `dp[j-1]` 已更新为当前行的值，而 `dp[j]` 存储的仍是上一行的值。

| 对比维度 | 二维 DP（本题代码） | 一维 DP（优化版） |
|---------|-----------------|-------------------|
| 空间复杂度 | $O(m \times n)$ | **$O(n)$** |
| 左上角获取 | 直接读 `dp[i-1][j-1]` | 需 `prev` 变量缓存 |
| 代码可读性 | 清晰直观 | 需理解缓存机制 |

### 5. 与相邻题目的对比

| 对比维度 | 5. 最长回文子串 | 97. 交错字符串 | **72. 编辑距离** |
|---------|--------------|--------------|-----------------|
| DP 类型 | 区间 DP | 二维路径 DP | **二维字符串 DP** |
| 状态含义 | `dp[l][r]` 子串是否回文 | `dp[i][j]` 是否可交错 | `dp[i][j]` 最少操作数 |
| DP 取值 | 布尔（是/否） | 布尔（是/否） | **整数（最小值）** |
| 递推结构 | 依赖左下 `dp[l+1][r-1]` | 依赖上 + 左 | **依赖左上 + 上 + 左（三方向）** |
| 遍历顺序 | 按子串长度递增 | 按行列递增 | 按行列递增 |
| 难度 | 中等 | 中等 | **困难** |
| 空间优化 | 可 O(n) | O(n) | O(n) |

编辑距离是二维字符串 DP 的巅峰题，其"三种操作对应三个子问题"的建模方式在序列对齐、拼写检查等实际场景中有广泛应用。

### 6. 复杂度分析

- **时间复杂度**：$O(m \times n)$，双层循环遍历整个 DP 矩阵。

- **空间复杂度**：本题代码为 $O(m \times n)$（二维 DP 数组）；优化版为 $O(n)$（一维滚动数组）。
