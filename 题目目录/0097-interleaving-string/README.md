## [97. 交错字符串](https://leetcode.cn/problems/interleaving-string/)

### 中等

给定三个字符串 `s1`、`s2`、`s3`，请你帮忙验证 `s3` 是否是由 `s1` 和 `s2` **交错**组成的。

两个字符串 `s` 和 `t` **交错**的定义如下，其中每个字符串会被分割成若干**非空**子字符串：
- `s = s₁ + s₂ + ... + sₙ`
- `t = t₁ + t₂ + ... + tₘ`
- `|n - m| ≤ 1`
- **交错**是 `s₁ + t₁ + s₂ + t₂ + ...` 或者 `t₁ + s₁ + t₂ + s₂ + ...`

**提示：** `a + b` 意味着字符串 `a` 和 `b` 连接。

<p><strong>示例 1:</strong></p>
<pre><strong>输入:</strong> s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"
<strong>输出:</strong> true
</pre>

<p><strong>示例 2:</strong></p>
<pre><strong>输入:</strong> s1 = "aabcc", s2 = "dbbca", s3 = "aadbbbaccc"
<strong>输出:</strong> false
</pre>

<p><strong>示例 3:</strong></p>
<pre><strong>输入:</strong> s1 = "", s2 = "", s3 = ""
<strong>输出:</strong> true
</pre>

---

## 题解：动态规划 — 二维网格路径

### 1. 核心思路：交错 = 在二维网格中选路

这道题是经典的二维字符串 DP。定义 `dp[i][j]` 表示 `s1` 的前 `i` 个字符和 `s2` 的前 `j` 个字符能否交错组成 `s3` 的前 `i + j` 个字符。

可以将其视为在一个 `(m+1) × (n+1)` 的网格中寻找一条从 `(0,0)` 到 `(m,n)` 的路径：
- **向下走一格**（`i → i+1`）：从 `s1` 取出一个字符
- **向右走一格**（`j → j+1`）：从 `s2` 取出一个字符

每一步必须满足：取出的字符与 `s3` 的对应位置字符匹配。

状态转移方程：

$$dp[i][j] = \underbrace{(dp[i-1][j] \land s_1[i-1] = s_3[i+j-1])}_{\text{从 s1 取字符}} \ \lor\ \underbrace{(dp[i][j-1] \land s_2[j-1] = s_3[i+j-1])}_{\text{从 s2 取字符}}$$

边界初始化：
- `dp[0][0] = True`（两个空串交错得到空串）
- 第一行 `dp[0][j]`：只能从 `s2` 取字符，对应 `s3` 的前缀必须与 `s2` 前缀完全匹配
- 第一列 `dp[i][0]`：只能从 `s1` 取字符，同理

---

### 2. 代码设计：合循环 + 前缀字符串比较

本题代码将首行、首列和内部格子的处理全部合并到**一个双层循环**中：

```python
for i in range(m + 1):
    for j in range(n + 1):
        if i == 0:
            dp[i][j] = s2[:j] == s3[:j]        # 首行：仅依赖 s2
        elif j == 0:
            dp[i][j] = s1[:i] == s3[:i]        # 首列：仅依赖 s1
        else:
            dp[i][j] = (dp[i-1][j] and s1[i-1] == s3[i+j-1]) \
                    or (dp[i][j-1] and s2[j-1] == s3[i+j-1])
```

**首行/首列的前缀比较方式**：

代码使用 `s2[:j] == s3[:j]`（字符串切片比较）而非递推 `dp[0][j-1] and s2[j-1] == s3[j-1]`。两种方式等价，切片比较更直观——直接验证"仅使用 `s2` 的前 j 个字符能否构成 `s3` 的前 j 个字符"。

时间复杂度上，切片比较在首行总计 $O(n^2)$ 开销，但算法整体仍为 $O(m \times n)$（主循环的二维递推占主导），可读性收益大于微小的常数代价。

### 3. 变量设计与迭代推演

| 变量 | 含义 | 初始值 |
|------|------|--------|
| `m, n` | `s1` 和 `s2` 的长度 | `len(s1)`, `len(s2)` |
| `dp` | `(m+1) × (n+1)` 布尔矩阵 | 全 `False` |
| 提前剪枝 | 若 `m + n ≠ len(s3)` 直接返回 `False` | — |

以 `s1 = "aab", s2 = "abc", s3 = "aaabbc"` 为例的推演过程：

**初始化首行（i = 0）：**

| j | s2[:j] | s3[:j] | 比较结果 | dp[0][j] |
|---|--------|--------|---------|-----------|
| 0 | `""` | `""` | `"" == ""` | **True** |
| 1 | `"a"` | `"a"` | `"a" == "a"` | **True** |
| 2 | `"ab"` | `"aa"` | `"ab" ≠ "aa"` | False |
| 3 | `"abc"` | `"aab"` | — | False |

**初始化首列（j = 0, i > 0）：**

| i | s1[:i] | s3[:i] | 比较结果 | dp[i][0] |
|---|--------|--------|---------|-----------|
| 1 | `"a"` | `"a"` | `"a" == "a"` | **True** |
| 2 | `"aa"` | `"aa"` | `"aa" == "aa"` | **True** |
| 3 | `"aab"` | `"aab"` | `"aab" == "aab"` | **True** |

**递推内部格子（i ≥ 1, j ≥ 1）：**

| (i,j) | s3[i+j-1] | 从 s1 来 | 从 s2 来 | dp[i][j] |
|-------|-----------|----------|----------|-----------|
| (1,1) | s3[1]='a' | dp[0][1]∧'a'=='a'=T | dp[1][0]∧'a'=='a'=T | **True** |
| (1,2) | s3[2]='a' | dp[0][2]∧'a'=='a'=F | dp[1][1]∧'b'=='a'=F | False |
| (2,1) | s3[2]='a' | dp[1][1]∧'a'=='a'=T | dp[2][0]∧'a'=='a'=T | **True** |
| (2,2) | s3[3]='b' | dp[1][2]∧'a'=='b'=F | dp[2][1]∧'b'=='b'=T | **True** |
| (2,3) | s3[4]='b' | dp[1][3]∧'a'=='b'=F | dp[2][2]∧'c'=='b'=F | False |
| (3,1) | s3[3]='b' | dp[2][1]∧'b'=='b'=T | dp[3][0]∧'a'=='b'=F | **True** |
| (3,2) | s3[4]='b' | dp[2][2]∧'b'=='b'=T | dp[3][1]∧'b'=='b'=T | **True** |
| (3,3) | s3[5]='c' | dp[2][3]∧'b'=='c'=F | dp[3][2]∧'c'=='c'=T | **True** |

返回 `dp[3][3] = True`。✅

DP 矩阵全貌：

| dp | j=0 | j=1 | j=2 | j=3 |
|----|-----|-----|-----|-----|
| i=0 | T | T | F | F |
| i=1 | T | T | F | F |
| i=2 | T | T | T | F |
| i=3 | T | T | T | **T** |

### 4. 空间优化：O(n) 一维滚动数组

由于 `dp[i][j]` 只依赖上一行和当前行左侧的值，可以用一维数组优化：

```python
def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
    m, n = len(s1), len(s2)
    if m + n != len(s3):
        return False
    dp = [False] * (n + 1)
    dp[0] = True
    for j in range(1, n + 1):
        dp[j] = dp[j - 1] and s2[j - 1] == s3[j - 1]
    for i in range(1, m + 1):
        dp[0] = dp[0] and s1[i - 1] == s3[i - 1]
        for j in range(1, n + 1):
            dp[j] = (dp[j] and s1[i - 1] == s3[i + j - 1]) \
                 or (dp[j - 1] and s2[j - 1] == s3[i + j - 1])
    return dp[n]
```

| 对比维度 | 二维 DP（本题代码） | 一维 DP（优化版） |
|---------|-----------------|-------------------|
| 空间复杂度 | $O(m \times n)$ | **$O(n)$** |
| 代码复杂度 | 合循环分支清晰 | 需理解滚动含义 |
| 首行/列处理 | 切片比较，直观 | 递推，$O(n)$ 常量更优 |

### 5. 与相邻 DP 题目的对比

| 对比维度 | 63. 不同路径 II | 64. 最小路径和 | **97. 交错字符串** |
|---------|---------------|--------------|-------------------|
| 网格 | 矩形（含障碍） | 矩形 | 矩形 |
| DP 含义 | 路径计数 | 最小路径和 | **是否存在合法交错** |
| DP 类型 | 计数累加 | 最优化取最小 | **布尔存在性判断** |
| 递推公式 | $dp[i][j]=dp[i-1][j]+dp[i][j-1]$ | $dp[i][j]=\min(dp[i-1][j],dp[i][j-1])+g[i][j]$ | $dp[i][j]=(dp[i-1][j] \land s_1[i-1]=s_3[...]) \lor (dp[i][j-1] \land s_2[j-1]=s_3[...])$ |
| 障碍物 | 有（值为 1） | 无 | **字符不匹配即"障碍"** |
| 空间优化 | $O(n)$ | $O(n)$ | $O(n)$ |

与 63 题的"障碍物清零"类似，交错字符串中的"字符不匹配"也起到了阻断作用——若当前字符与 `s3` 对应位置不一致，`dp[i][j]` 无法从该方向转移而来。

---

### 6. 复杂度分析

- **时间复杂度**：$O(m \times n)$，双层循环遍历整个 DP 矩阵。

- **空间复杂度**：本题代码为 $O(m \times n)$（二维 DP 数组）；优化版为 $O(n)$（一维滚动数组）。
