## [118. 杨辉三角](https://leetcode.cn/problems/pascals-triangle/)

### 简单

给定一个非负整数 `numRows`，生成「杨辉三角」的前 `numRows` 行。

在「杨辉三角」中，每个数是它左上方和右上方的数的和。

**示例 1：**
<pre><strong>输入：</strong>numRows = 5
<strong>输出：</strong>[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
</pre>

**示例 2：**
<pre><strong>输入：</strong>numRows = 1
<strong>输出：</strong>[[1]]
</pre>

---

## 题解：迭代动态规划

### 1. 核心规律

杨辉三角的递推公式极为简洁——每个内部元素等于上一行相邻两数之和：

```
row[i][j] = row[i-1][j-1] + row[i-1][j]
```

每行的首尾元素恒为 `1`。这条规律直接驱动了整个构造过程。

---

### 2. 实现分析：以"上一行"为基的逐行构造

你的代码采用了一种干净利落的迭代模式：

```python
ans = [[1]]                          # 第 0 行作为基底
for i in range(1, numRows):          # 从第 1 行开始构造
    r = [1]                          # 每行以 1 开头
    for j in range(1, i):            # 填充中间元素
        r.append(ans[-1][j-1] + ans[-1][j])  # 左上 + 右上
    r.append(1)                      # 每行以 1 结尾
    ans.append(r)
```

以 `numRows = 5` 追踪构造过程：

| 轮次 (i) | `ans[-1]`（上一行） | 中间计算 | 生成行 `r` |
|-----------|---------------------|----------|------------|
| 0 | — | — | `[1]` |
| 1 | `[1]` | j 从 1 到 0，无中间元素 | `[1, 1]` |
| 2 | `[1, 1]` | j=1: `1+1=2` | `[1, 2, 1]` |
| 3 | `[1, 2, 1]` | j=1: `1+2=3`, j=2: `2+1=3` | `[1, 3, 3, 1]` |
| 4 | `[1, 3, 3, 1]` | j=1: `1+3=4`, j=2: `3+3=6`, j=3: `3+1=4` | `[1, 4, 6, 4, 1]` |

---

### 3. 逻辑亮点

#### A. 用 `ans[-1]` 指代上一行

不必维护额外的 `prev_row` 变量，直接通过 `ans[-1]` 访问最新生成的一行，代码更紧凑。

#### B. 内层循环边界 `range(1, i)`

第 `i` 行的长度为 `i + 1`，其中首尾已固定为 `1`，只需填充 `i - 1` 个中间元素。`range(1, i)` 恰好覆盖 `j = 1` 到 `j = i-1`，共 `i-1` 个位置，边界天然正确。

---

### 4. 复杂度分析

- **时间复杂度**：$O(n^2)$，其中 $n$ = `numRows`。总共生成 $1 + 2 + \dots + n = \frac{n(n+1)}{2}$ 个元素，每个元素 $O(1)$ 计算。

- **空间复杂度**：$O(n^2)$，存储所有行的结果。若不计算返回值，辅助空间为 $O(1)$。

---

### 延伸思考

- 本题是最基础的二维动态规划，递推关系天然给出，无须额外推导状态转移方程。
- [119. 杨辉三角 II](https://leetcode.cn/problems/pascals-triangle-ii/) 要求只返回第 `k` 行，需要将空间优化至 $O(k)$，常用倒序更新的滚动数组实现。
- 杨辉三角与组合数 $C(n, k)$ 一一对应——第 $n$ 行第 $k$ 个元素恰好是二项式系数 $\binom{n}{k}$。
