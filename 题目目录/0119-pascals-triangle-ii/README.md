## [119. 杨辉三角 II](https://leetcode.cn/problems/pascals-triangle-ii/)

### 简单

给定一个非负索引 `rowIndex`，返回「杨辉三角」的第 `rowIndex` 行（行索引从 0 开始）。

在「杨辉三角」中，每个数是它左上方和右上方的数的和。

**示例 1：**
<pre><strong>输入：</strong>rowIndex = 3
<strong>输出：</strong>[1,3,3,1]
</pre>

**示例 2：**
<pre><strong>输入：</strong>rowIndex = 0
<strong>输出：</strong>[1]
</pre>

**示例 3：**
<pre><strong>输入：</strong>rowIndex = 1
<strong>输出：</strong>[1,1]
</pre>

**进阶**：你可以优化你的算法到 $O(rowIndex)$ 空间复杂度吗？

---

## 题解：倒序遍历 + 原地滚动数组

### 1. 与 118 题的关系

[118. 杨辉三角](https://leetcode.cn/problems/pascals-triangle/) 要求返回全部行，而本题只需返回第 `rowIndex` 行。如果沿用 118 的二维数组做法，空间为 $O(k^2)$，不符合进阶要求的 $O(k)$ 空间。

本题的核心挑战在于：**仅用一个一维数组，在反复覆盖中保证计算的正确性**。

---

### 2. 核心思路：倒序遍历 + 动态增长

你的代码采用了一种巧妙的策略——数组**边更新边增长**：

```python
ans = [1]                              # 第 0 行
for i in range(rowIndex):              # 迭代 rowIndex 次
    for j in range(i, 0, -1):          # 倒序更新内部元素
        ans[j] = ans[j - 1] + ans[j]   # 左上 + 右上
    ans.append(1)                      # 末尾补 1
```

以 `rowIndex = 3` 追踪整个过程：

| i | 循环前 `ans` | 倒序更新过程 | append(1) 后 |
|---|-------------|-------------|-------------|
| 0 | `[1]` | j 从 0 到 1（空循环） | `[1, 1]` |
| 1 | `[1, 1]` | j=1: `ans[1]=1+1=2` | `[1, 2, 1]` |
| 2 | `[1, 2, 1]` | j=2: `ans[2]=2+1=3` → j=1: `ans[1]=1+2=3` | `[1, 3, 3, 1]` |

---

### 3. 逻辑亮点：为什么必须倒序遍历？

这是本题最关键的设计决策。以 `i = 2` 时的 `ans = [1, 2, 1]` 为例：

- **正确做法（倒序）**：先更新 `j=2`，再更新 `j=1`。更新 `j=1` 时用到的 `ans[1]=2` 尚未被本轮覆盖，仍是上一轮的正确值。

- **错误做法（正序）**：若先更新 `j=1`，`ans[1]` 会被改为新值 `3`。再更新 `j=2` 时，读取的 `ans[1]` 已经是 `3` 而非期望的 `2`，导致 `ans[2] = 3 + 1 = 4`，结果错误。

倒序遍历的核心在于：**确保当前元素在其右侧元素被更新之前完成自己的更新**，从而每个元素在本次迭代中只被写一次、读到的旧值也来自上一轮。

---

### 4. 动态增长的巧妙之处

不同于常规写法预先分配 `rowIndex + 1` 长度的数组，你的代码让 `ans` 随迭代逐步增长：

- 初始长度为 1（第 0 行）
- 每轮迭代末尾 `append(1)`，长度 +1

这样做的优势：
- 省去了预分配和填充 0 的步骤
- 数组长度始终等于"当前已构造的行长度"，逻辑直观
- 倒序更新时天然避开了新增的尾部元素

---

### 5. 复杂度分析

- **时间复杂度**：$O(k^2)$，其中 $k$ = `rowIndex`。总共执行 $0 + 1 + \dots + (k-1) = \frac{k(k-1)}{2}$ 次内层更新，每个操作 $O(1)$。

- **空间复杂度**：$O(k)$，仅使用单个长度为 $k+1$ 的一维数组，满足进阶要求。

---

### 延伸思考

- 倒序更新本质上是一种**滚动数组**技术，在背包问题、编辑距离等 DP 中广泛应用——只要状态转移只依赖上一轮的值，就可以通过倒序遍历将二维压缩为一维。
- 杨辉三角的每一行也是组合数 $\binom{n}{0}, \binom{n}{1}, \dots, \binom{n}{n}$，理论上可逐项用公式 $\binom{n}{k} = \binom{n}{k-1} \cdot \frac{n-k+1}{k}$ 直接计算，但整数运算可能有精度问题。
