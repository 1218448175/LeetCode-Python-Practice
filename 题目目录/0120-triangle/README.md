## [120. 三角形最小路径和](https://leetcode.cn/problems/triangle/)

### 中等

给定一个三角形 `triangle`，找出自顶向下的最小路径和。

每一步只能移动到下一行中相邻的结点上（下标 `i` 相同或下标 `i + 1`）。

<p><strong>示例 1:</strong></p>
<pre><strong>输入:</strong> triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
<strong>输出:</strong> 11
<strong>解释:</strong> 如下面简图所示：
   2
  3 4
 6 5 7
4 1 8 3
自顶向下的最小路径和为 11（即 2 + 3 + 5 + 1 = 11）。
</pre>

<p><strong>示例 2:</strong></p>
<pre><strong>输入:</strong> triangle = [[-10]]
<strong>输出:</strong> -10
</pre>

---

## 题解：动态规划 — 自顶向下 + 二维 DP

### 1. 核心思路：逐行递推最小路径和

这道题是经典的二维动态规划问题。定义 `dp[i][j]` 表示从顶部走到第 `i` 行第 `j` 列的最小路径和。

状态转移分析：

- 对于第 `i` 行的第 `j` 个元素，它只能从上一行的两个相邻位置转移而来：
  - 从左上角 `(i-1, j-1)` 移动过来
  - 从正上方 `(i-1, j)` 移动过来
- 选择两者中较小的路径和，加上当前元素值

边界情况：
- **左边界 `j == 0`**：只能从正上方 `dp[i-1][0]` 转移
- **右边界 `j == i`**：只能从左上角 `dp[i-1][i-1]` 转移

状态转移方程：

$$dp[i][j] =
\begin{cases}
dp[i-1][0] + triangle[i][0], & j = 0 \\[4pt]
dp[i-1][i-1] + triangle[i][i], & j = i \\[4pt]
\min(dp[i-1][j-1],\ dp[i-1][j]) + triangle[i][j], & 0 < j < i
\end{cases}$$

最终答案：`min(dp[-1])`，即最后一行所有位置的最小值。

---

### 2. 变量设计与迭代推演

| 变量 | 含义 | 初始值 |
|------|------|--------|
| `n` | 三角形的行数 | `len(triangle)` |
| `dp` | 二维 DP 数组，`dp[i][j]` 表示到 `(i, j)` 的最小路径和 | `[[0] * (i+1) for i in range(n)]` |

以 `triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]` 为例的推演过程：

| i | j | triangle[i][j] | 转移来源 | 计算过程 | dp[i][j] |
|---|----|----------------|----------|----------|----------|
| 0 | 0 | 2 | 起始行 | `dp[-1][0] + 2` 即 `0 + 2` | **2** |
| 1 | 0 | 3 | 左边界，上方 | `dp[0][0] + 3 = 2 + 3` | **5** |
| 1 | 1 | 4 | 右边界，左上 | `dp[0][0] + 4 = 2 + 4` | **6** |
| 2 | 0 | 6 | 左边界，上方 | `dp[1][0] + 6 = 5 + 6` | **11** |
| 2 | 1 | 5 | 上方/左上取小 | `min(5, 6) + 5 = 5 + 5` | **10** |
| 2 | 2 | 7 | 右边界，左上 | `dp[1][1] + 7 = 6 + 7` | **13** |
| 3 | 0 | 4 | 左边界，上方 | `dp[2][0] + 4 = 11 + 4` | **15** |
| 3 | 1 | 1 | 上方/左上取小 | `min(11, 10) + 1 = 10 + 1` | **11** |
| 3 | 2 | 8 | 上方/左上取小 | `min(10, 13) + 8 = 10 + 8` | **18** |
| 3 | 3 | 3 | 右边界，左上 | `dp[2][2] + 3 = 13 + 3` | **16** |

最后一行 `dp[3] = [15, 11, 18, 16]`，最小值为 **11**。

### 3. 代码中的巧妙之处：Python 负索引处理首行边界

本题代码中存在一个值得注意的细节：

```python
for i in range(n):
    for j in range(i + 1):
        if j == 0:
            dp[i][j] = dp[i - 1][j] + triangle[i][j]  # i=0 时 dp[-1][0]
```

当 `i = 0` 时，`dp[-1]` 在 Python 中指向 `dp` 数组的最后一行 `dp[n-1]`。由于 `dp` 已用全零初始化，`dp[-1][0] = 0`，加上 `triangle[0][0]` 恰好得到正确结果。

这是一个利用 Python 语言特性的"巧合正确"，实际等效于 `dp[0][0] = triangle[0][0]`。理解这一细节有助于深入理解 DP 边界处理的多种实现方式。

### 4. 空间优化：自底向上 O(n) 解法（推荐）

本题的标准最优解是**自底向上**递推，用一维数组即可：

```python
def minimumTotal(self, triangle: List[List[int]]) -> int:
    dp = triangle[-1][:]          # 初始化为最后一行的拷贝
    for i in range(len(triangle) - 2, -1, -1):
        for j in range(i + 1):
            dp[j] = triangle[i][j] + min(dp[j], dp[j + 1])
    return dp[0]
```

核心思想：从倒数第二行向上，每个位置更新为**当前值 + 下一行相邻两个位置的最小值**。`dp[j]` 和 `dp[j+1]` 分别对应下一行同下标和下标+1 的两个邻接点。

与本题代码的对比：

| 对比维度 | 自顶向下（本题代码） | 自底向上（优化版） |
|---------|-----------------|-------------------|
| 递推方向 | 从上到下，最后取 min(dp[-1]) | 从下到上，最终答案在 dp[0] |
| 空间复杂度 | $O(n^2)$，二维数组 | **$O(n)$，一维数组** |
| 索引处理 | 需要区分左/右/中间三种边界 | 无需边界判断，每行天然有 `j` 和 `j+1` 两个邻接 |
| 代码简洁度 | 较多条件分支 | 极简双循环 |

### 5. 与相邻 DP 题目的对比

| 对比维度 | 70. 爬楼梯 | 198. 打家劫舍 | 120. 三角形最小路径和 |
|---------|-----------|-------------|---------------------|
| DP 维度 | 一维线性 | 一维线性 | **二维矩阵** |
| 递推公式 | $f(i) = f(i-1) + f(i-2)$ | $dp[i] = \max(dp[i-2] + nums[i], dp[i-1])$ | $dp[i][j] = \min(dp[i-1][j-1], dp[i-1][j]) + t[i][j]$ |
| 决策类型 | 数量累加 | 最优化取最大 | **最优化取最小** |
| 空间优化 | $O(1)$ 双变量 | $O(1)$ 双变量 | **$O(n)$ 一维数组** |
| 遍历方向 | 单向从左到右 | 单向从左到右 | 可自顶向下或**自底向上** |

三角形最小路径和是二维 DP 的入门题，相比一维 DP，多了"行内位置选择"这一维度。理解自底向上的空间优化思路，是掌握二维 DP 降维的关键。

### 6. 复杂度分析

- **时间复杂度**：$O(n^2)$，其中 $n$ 为三角形行数。每个元素访问一次，三角形共有 $\frac{n(n+1)}{2}$ 个元素。

- **空间复杂度**：本题代码为 $O(n^2)$（二维 DP 数组）；优化版为 $O(n)$（一维数组滚动更新）。
