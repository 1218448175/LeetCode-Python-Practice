## [123. 买卖股票的最佳时机 III](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iii/)

### 困难

给定一个数组，它的第 `i` 个元素是一支给定的股票在第 `i` 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成**两笔**交易。

**注意：** 你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

<p><strong>示例 1:</strong></p>
<pre><strong>输入:</strong> prices = [3,3,5,0,0,3,1,4]
<strong>输出:</strong> 6
<strong>解释:</strong> 在第 4 天（股价 = 0）买入，在第 6 天（股价 = 3）卖出，利润 = 3。
     随后在第 7 天（股价 = 1）买入，在第 8 天（股价 = 4）卖出，利润 = 3。
     总利润 = 6。
</pre>

<p><strong>示例 2:</strong></p>
<pre><strong>输入:</strong> prices = [1,2,3,4,5]
<strong>输出:</strong> 4
<strong>解释:</strong> 全程上涨，一次交易即可获取全部利润。
</pre>

<p><strong>示例 3:</strong></p>
<pre><strong>输入:</strong> prices = [7,6,4,3,1]
<strong>输出:</strong> 0
<strong>解释:</strong> 全程下跌，不交易利润最大。
</pre>

---

## 题解：动态规划 — 五状态机模型

### 1. 核心思路：将"最多两笔交易"转化为状态机

本题是股票系列的进阶题，限制**最多两笔交易**。核心洞察是将每天结束时可能的状态定义为 **5 种**：

| 状态 | 含义 | 持有股票？ | 已完成交易数 |
|------|------|----------|------------|
| 0 | 从未操作 | 否 | 0 |
| 1 | 第一次买入后 | 是 | 0（持有中） |
| 2 | 第一次卖出后 | 否 | 1 |
| 3 | 第二次买入后 | 是 | 1（持有中） |
| 4 | 第二次卖出后 | 否 | 2 |

状态转移构成一条单向链：`0 → 1 → 2 → 3 → 4`，每个状态也可以"保持不动"（沿用前一天的值）。

定义 `dp[i][s]` 表示第 `i` 天结束时处于状态 `s` 的最大利润。

---

### 2. 状态转移方程

$$dp[i][0] = 0$$

$$dp[i][1] = \max(dp[i][0] - prices[i],\ dp[i-1][1]) \quad \text{(今天买入 或 保持昨日的买入)}$$

$$dp[i][2] = \max(dp[i][1] + prices[i],\ dp[i-1][2]) \quad \text{(今天卖出 或 保持昨日的卖出)}$$

$$dp[i][3] = \max(dp[i][2] - prices[i],\ dp[i-1][3]) \quad \text{(今天第二次买入 或 保持)}$$

$$dp[i][4] = \max(dp[i][3] + prices[i],\ dp[i-1][4]) \quad \text{(今天第二次卖出 或 保持)}$$

**初始条件（第 0 天）：**
- `dp[0][0] = 0`
- `dp[0][1] = -prices[0]` — 第 0 天买入，利润为负
- `dp[0][2] = 0`
- `dp[0][3] = -prices[0]` — 允许同一天完成一轮买卖后再买入，效果等价于只买一次
- `dp[0][4] = 0`

---

### 3. 变量设计与迭代推演

| 变量 | 含义 | 初始值 |
|------|------|--------|
| `n` | 数组长度 | `len(prices)` |
| `dp` | `n × 5` 矩阵 | 全零，`dp[0][1]=dp[0][3]=-prices[0]` |

以 `prices = [3,3,5,0,0,3,1,4]` 为例，逐日推演仅展示四状态的 dp 值（状态 0 恒为 0）：

| 天 | 价格 | buy1 | sell1 | buy2 | sell2 | 关键事件 |
|----|------|------|-------|------|-------|---------|
| 0 | 3 | **-3** | 0 | **-3** | 0 | 初始化：两种"买入"状态均为 -3 |
| 1 | 3 | -3 | 0 | -3 | 0 | 价格未变，无更优操作 |
| 2 | 5 | -3 | **2** | -3 | 2 | ↑ 卖出获利 2（5-3） |
| 3 | 0 | **0** | 2 | **2** | 2 | ↓ 价格触底，`buy1` 优化为 0（在价格 0 买入），`buy2` 用 sell1 的 2 元利润买入 |
| 4 | 0 | 0 | 2 | 2 | 2 | 价格停留 0，无变化 |
| 5 | 3 | 0 | **3** | 2 | 5 | ↑ 第一次卖出获利 3（3-0），但 `buy2` 不跟（3-3=0 < 原值 2） |
| 6 | 1 | 0 | 3 | **2** | 5 | `buy2` = max(3-1, 2) = 2，在价格 1 买入或保持原值，二者等价 |
| 7 | 4 | 0 | 4 | 2 | **6** | ↑ `sell2` = 2+4 = 6：第二次卖出获利 |

返回 `max(dp[7]) = 6`。✅

**路径还原**：`buy1(day3,0元) → sell1(day5,3元) → buy2(day6,1元) → sell2(day7,4元)`，利润 = (3-0) + (4-1) = 6。

---

### 4. 代码结构分析

```python
dp = [[0] * 5 for _ in range(n)]
dp[0][1] = -prices[0]    # buy1 初始值
dp[0][3] = -prices[0]    # buy2 初始值（允许当天完成第一轮后立即买入第二轮）

for i in range(1, n):
    dp[i][0] = 0
    dp[i][1] = max(dp[i][0] - prices[i], dp[i - 1][1])   # 买1
    dp[i][2] = max(dp[i][1] + prices[i], dp[i - 1][2])   # 卖1
    dp[i][3] = max(dp[i][2] - prices[i], dp[i - 1][3])   # 买2
    dp[i][4] = max(dp[i][3] + prices[i], dp[i - 1][4])   # 卖2
```

注意 `dp[i][1]` 使用的是**当前行**的 `dp[i][0]` 而非上一行。这允许在同一天内完成"不做任何操作然后买入"，由于 `dp[i][0]` 恒为 0，实际效果与使用 `dp[i-1][0]` 等价。

---

### 5. 空间优化：O(1) 四变量

由于每天只依赖前一天的值，可直接用 4 个变量代替 DP 矩阵：

```python
def maxProfit(self, prices: List[int]) -> int:
    buy1, sell1 = -prices[0], 0
    buy2, sell2 = -prices[0], 0
    for i in range(1, len(prices)):
        buy1  = max(buy1, -prices[i])           # 第一次买入
        sell1 = max(sell1, buy1 + prices[i])     # 第一次卖出
        buy2  = max(buy2, sell1 - prices[i])     # 第二次买入
        sell2 = max(sell2, buy2 + prices[i])     # 第二次卖出
    return sell2
```

注意循环内的更新顺序：`sell1` 使用的 `buy1` 是当天刚更新的值，`buy2` 使用的 `sell1` 也是当天刚更新的值。这保证了同一天内可以完成多步状态转移（但不会产生非法操作，因为价格相同）。

| 对比维度 | 二维 DP（本题代码） | O(1) 四变量（优化版） |
|---------|-----------------|---------------------|
| 空间复杂度 | $O(n)$ | **$O(1)$** |
| 代码行数 | 10 行 | 6 行 |
| 可读性 | 状态转移直观 | 需要理解变量含义 |
| 可扩展性 | 易于扩展到 k 次交易 | 交易次数增多时代码膨胀 |

### 6. 股票系列的递进关系

| 题号 | 交易限制 | 核心技巧 | 难度 |
|------|---------|---------|------|
| [121](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/) | 最多 1 笔 | 一次遍历维护最低价 | 简单 |
| [122](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/) | 不限次数 | 贪心累加所有上涨段 | 中等 |
| **123** | **最多 2 笔** | **5 状态机 DP** | **困难** |
| [188](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/) | 最多 k 笔 | 通用 2k+1 状态机 DP | 困难 |

从 121 到 123 的演进体现了 DP 状态机模型的威力：交易次数限制从 1→∞→2→k，状态机也从 3 状态 → 贪心 → 5 状态 → 2k+1 状态逐步泛化。

---

### 7. 复杂度分析

- **时间复杂度**：$O(n)$，一次遍历。

- **空间复杂度**：本题代码为 $O(n)$（`n × 5` 矩阵）；优化版为 $O(1)$（4 个变量）。
