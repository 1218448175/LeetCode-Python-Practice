## [136. 只出现一次的数字](https://leetcode.cn/problems/single-number/)

### 简单

给你一个 **非空** 整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现**两次**。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

**示例 1：**

<pre><strong>输入：</strong>nums = [2,2,1]
<strong>输出：</strong>1
</pre>

**示例 2：**

<pre><strong>输入：</strong>nums = [4,1,2,1,2]
<strong>输出：</strong>4
</pre>

**示例 3：**

<pre><strong>输入：</strong>nums = [1]
<strong>输出：</strong>1
</pre>

**提示：**

- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 除了某个元素只出现一次以外，其余每个元素均出现两次。

---

## 题解：异或运算 — 利用"自反性"消除成对元素

### 1. 核心思路：异或的三个性质

异或（XOR，符号 `^`）是一种按位运算，规则是"相同为 0，不同为 1"。它有三个关键性质：

| 性质 | 表达式 | 含义 |
|------|--------|------|
| **自反性** | `a ^ a = 0` | 任意数与自身异或结果为 0 |
| **恒等性** | `a ^ 0 = a` | 任意数与 0 异或结果为其自身 |
| **交换律与结合律** | `a ^ b ^ a = b` | 异或顺序不影响最终结果 |

> **直觉理解**：如果把异或看作"翻转开关"——按一下开，再按一下关——那么每个出现两次的数就是按了两次开关，最终回到原位；而只出现一次的数只按了一次，留在最终结果中。

---

### 2. 执行逻辑的详细拆解

```python
ans = 0
for num in nums:
    ans = ans ^ num
return ans
```

初始 `ans = 0`，遍历数组中的每个数 `num`，将 `ans` 与 `num` 异或后赋值回 `ans`。

以 `nums = [4, 1, 2, 1, 2]` 为例，手动推演：

```
初始:   ans = 0
0  ^ 4  → 4      (0 ^ 任何数 = 该数本身)
4  ^ 1  → 5      (0100 ^ 0001 = 0101)
5  ^ 2  → 7      (0101 ^ 0010 = 0111)
7  ^ 1  → 6      (0111 ^ 0001 = 0110)   ← 1 出现了第二次，被消除
6  ^ 2  → 4      (0110 ^ 0010 = 0100)   ← 2 出现了第二次，被消除
返回 4 ✅
```

可以看到，`1` 和 `2` 各出现了两次，异或后分别被抵消归零，最终只剩下出现一次的 `4`。

> **从位的视角看**：每一位上，如果有偶数个 1，异或结果为 0；如果有奇数个 1，异或结果为 1。由于每个数出现两次（偶数次），它们对每一位的贡献都被抵消，只有出现一次的那个数贡献了有效位。

---

### 3. 逻辑亮点

- **一次遍历即得结果**：不需要哈希表存储出现次数，不需要排序，不需要额外的数据结构。仅用一个变量 `ans`，一边遍历一边异或，天然符合 O(1) 空间的要求。

- **交换律是天然屏障**：无论成对元素在数组中如何分布（相邻或远离），异或的交换律保证它们最终都会被抵消。例如 `[2, 1, 2]` → `2 ^ 1 ^ 2 = 2 ^ 2 ^ 1 = 0 ^ 1 = 1`。

- **利用"自反性"消除**：这是本题最精妙的核心，也是很多位运算问题（如找不同、找缺失数字）的通用技巧。`a ^ a = 0` 意味着任何数异或自己就"消失"了，这是一种**无损消除**——不丢失真正需要保留的信息。

- **无需类型转换**：直接将整数进行异或运算，不涉及二进制字符串的构造和解析，代码极端简洁。

---

### 4. 复杂度分析

- **时间复杂度**：$O(n)$。一次遍历数组，每个元素仅参与一次异或运算。

- **空间复杂度**：$O(1)$。仅使用一个变量 `ans`，不随输入规模增长。

---

### 5. 对比其他解法

#### 方法一：哈希表（空间 O(n)）

```python
class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        seen = set()
        for num in nums:
            if num in seen:
                seen.remove(num)
            else:
                seen.add(num)
        return seen.pop()
```

此方法同样一次遍历，但使用哈希集合存储未配对的元素，空间复杂度为 O(n)，不满足题目"常量额外空间"的要求。

#### 方法二：数学公式（存在溢出风险）

```python
def singleNumber(nums):
    return 2 * sum(set(nums)) - sum(nums)
```

公式 `2 × sum(去重) - sum(原数组) = 只出现一次的数` 的思路直观，但需要 O(n) 空间构建集合，且存在大数累加溢出风险（Python 中不会溢出，但其他语言中需注意）。

#### 方法三：排序后遍历（时间 O(n log n)）

先排序再成对比较，时间复杂度 O(n log n)，且可能修改原数组，不如异或法优雅。

| 方法 | 时间复杂度 | 空间复杂度 | 满足要求 |
|------|-----------|-----------|---------|
| **异或法** | **O(n)** | **O(1)** | ✅ |
| 哈希表 | O(n) | O(n) | ❌ |
| 数学公式 | O(n) | O(n) | ❌ |
| 排序遍历 | O(n log n) | O(1) | ❌ |

### 代码回顾

```python
class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        ans = 0
        for num in nums:
            ans = ans ^ num
        return ans
```

> **一句总结**：利用异或的交换律让成对元素互相抵消，最终答案自然浮出水面。这是位运算"无损消除"思想的入门经典。
