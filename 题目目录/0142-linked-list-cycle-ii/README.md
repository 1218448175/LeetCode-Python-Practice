## [142. 环形链表 II](https://leetcode.cn/problems/linked-list-cycle-ii/)

### 中等

给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。如果链表无环，则返回 `null`。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。如果 `pos` 是 `-1`，则在该链表中没有环。

**注意：不允许修改链表。**

**示例 1：**
<pre><strong>输入：</strong>head = [3,2,0,-4], pos = 1
<strong>输出：</strong>返回索引为 1 的链表节点（值为 2 的节点）
<strong>解释：</strong>链表中有一个环，其尾部连接到第二个节点。
</pre>

**示例 2：**
<pre><strong>输入：</strong>head = [1,2], pos = 0
<strong>输出：</strong>返回索引为 0 的链表节点（值为 1 的节点）
</pre>

**示例 3：**
<pre><strong>输入：</strong>head = [1], pos = -1
<strong>输出：</strong>返回 null
</pre>

**进阶**：你是否可以使用 $O(1)$ 空间复杂度解决此题？

---

## 题解：Floyd 快慢指针（两阶段探测）

### 1. 与 141 题的关系

[141. 环形链表](https://leetcode.cn/problems/linked-list-cycle/) 只需判断是否有环，快慢指针相遇即可返回。本题在此基础上要求定位环的入口节点，需要利用相遇点的数学性质进行第二阶段的搜索。

---

### 2. 核心思路：两阶段 Floyd 算法

你的代码实现了经典的 Floyd 判圈算法，分为两个阶段：

**阶段一：判环（快慢指针相遇）**

```python
slow = fast = head
while fast and fast.next:
    slow = slow.next        # 慢指针每次走 1 步
    fast = fast.next.next   # 快指针每次走 2 步
    if fast is slow:        # 相遇 → 有环，进入阶段二
```

**阶段二：定位环入口（同步同速前进）**

```python
while slow is not head:     # head 从链表头出发，slow 从相遇点出发
    slow = slow.next        # 两者每次都走 1 步
    head = head.next
return slow                  # 再次相遇点 = 环入口
```

---

### 3. 数学证明：为什么 head 和 slow 同步走会在入口相遇？

设：

- 链表头到环入口的距离为 $L$
- 环入口到相遇点的距离为 $x$
- 环的长度为 $C$

相遇时：
- 慢指针走了 $L + x$ 步
- 快指针走了 $L + x + kC$ 步（多绕了 $k$ 圈）
- 快指针速度是慢指针的 2 倍：$2(L + x) = L + x + kC$
- 化简得：$L = kC - x = (k-1)C + (C - x)$

**关键结论**：从链表头走 $L$ 步到达环入口；从相遇点走 $L$ 步也恰好到达环入口（因为 $(k-1)C$ 是整圈绕回，$(C-x)$ 是相遇点走到环入口的距离）。

因此，`head` 从头出发、`slow` 从相遇点同时出发，每次各走 1 步，两者必在环入口相遇。

---

### 4. 逻辑亮点：复用 `head` 指针

你的代码没有引入额外变量，而是直接用 `head` 作为"从链表头发出的指针"：

```python
while slow is not head:
    slow = slow.next
    head = head.next
```

注意这里的 `head` 是函数参数（局部变量），对它赋值不会影响外部调用者。这种写法减少了变量数量，代码更紧凑。

---

### 5. 复杂度分析

- **时间复杂度**：$O(n)$。
  - 阶段一：慢指针最多走 $n$ 步（无环时到链表尾），有环时相遇前也不超过 $n$ 步。
  - 阶段二：从相遇点到环入口再至多走 $n$ 步。
  - 综合 $O(n)$。

- **空间复杂度**：$O(1)$，仅使用两个指针变量，满足进阶要求。

---

### 延伸思考

- Floyd 判圈算法最早由 Robert W. Floyd 提出，最初用于检测伪随机数生成器的周期，后被广泛应用于链表环检测。
- 相比于哈希表解法（需要 $O(n)$ 额外空间），快慢指针将空间压缩到了 $O(1)$，是链表中"用时间换空间"的经典案例。
- [287. 寻找重复数](https://leetcode.cn/problems/find-the-duplicate-number/) 也是 Floyd 判圈算法的典型应用——将数组下标映射为链表节点，重复数就是环的入口。
