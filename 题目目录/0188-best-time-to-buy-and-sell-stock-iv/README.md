## [188. 买卖股票的最佳时机 IV](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/)

### 困难

给你一个整数数组 `prices` 和一个整数 `k`，其中 `prices[i]` 是某支给定的股票在第 `i` 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 **`k` 笔**交易。也就是说，你最多可以买 `k` 次，卖 `k` 次。

**注意：** 你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

<p><strong>示例 1:</strong></p>
<pre><strong>输入:</strong> k = 2, prices = [2,4,1]
<strong>输出:</strong> 2
<strong>解释:</strong> 第 1 天（股价 = 2）买入，第 2 天（股价 = 4）卖出，利润 = 2。
</pre>

<p><strong>示例 2:</strong></p>
<pre><strong>输入:</strong> k = 2, prices = [3,2,6,5,0,3]
<strong>输出:</strong> 7
<strong>解释:</strong> 第 2 天（股价 = 2）买入，第 3 天（股价 = 6）卖出，利润 = 4。
     随后第 5 天（股价 = 0）买入，第 6 天（股价 = 3）卖出，利润 = 3。
     总利润 = 7。
</pre>

---

## 题解：动态规划 — 泛化 2k+1 状态机 + O(k) 一维滚动

### 1. 核心思路：从 123 题的 5 状态泛化到 2k+1 状态

本题是 [123. 买卖股票的最佳时机 III](./题目目录/0123-best-time-to-buy-and-sell-stock-iii) 的泛化版本。123 题限制 `k = 2`，定义了 5 个状态（0, buy1, sell1, buy2, sell2）。本题将 `k` 作为参数，自然扩展到 `2k + 1` 个状态：

| 状态索引 | 含义 | 持有股票？ |
|---------|------|----------|
| 0 | 从未操作 | 否 |
| 1 | 第 1 次买入后 | 是 |
| 2 | 第 1 次卖出后 | 否 |
| 3 | 第 2 次买入后 | 是 |
| 4 | 第 2 次卖出后 | 否 |
| ... | ... | ... |
| `2k-1` | 第 k 次买入后 | 是 |
| `2k` | 第 k 次卖出后 | 否 |

奇数索引为"买入后"状态，偶数索引（>0）为"卖出后"状态。

状态转移方程（对每笔交易 j = 1, 2, ..., k）：

$$\begin{aligned}
dp[2j-1] &= \max(dp[2j-2] - prices[i],\ dp[2j-1]) \quad &\text{(第 j 次买入)} \\[4pt]
dp[2j] &= \max(dp[2j-1] + prices[i],\ dp[2j]) \quad &\text{(第 j 次卖出)}
\end{aligned}$$

初始化（第 0 天）：
- `dp[0] = 0`
- 所有奇数位 `dp[2j-1] = -prices[0]`（第 0 天买入，利润为负）
- 所有偶数位 `dp[2j] = 0`

---

### 2. 代码的精妙之处：一维数组原地更新

```python
dp = [0] * (2 * k + 1)
for j in range(1, k + 1):
    dp[2 * j - 1] = -prices[0]    # 初始化所有"买入"状态

for i in range(1, n):
    for j in range(1, k + 1):
        dp[2 * j - 1] = max(dp[2 * j - 2] - prices[i], dp[2 * j - 1])  # buy_j
        dp[2 * j]     = max(dp[2 * j - 1] + prices[i], dp[2 * j])      # sell_j
```

**原地更新的可行性分析**：

`dp[2j-1]`（buy_j）依赖 `dp[2j-2]`（sell_{j-1}），而 `sell_{j-1}` 在内层循环的前一次迭代中已被更新为**当天**的值。这意味着同一天内链式转移 `sell_{j-1} → buy_j → sell_j` 是允许的，并且不影响最终结果（因为 `prices[i]` 相同，操作抵消）。

**与 123 题代码的对应关系**：

| 123 题（k=2） | 188 题（泛化 k） |
|--------------|-----------------|
| `dp[0]` | `dp[0]` |
| `dp[1]` = buy1 | `dp[1]` = buy1 |
| `dp[2]` = sell1 | `dp[2]` = sell1 |
| `dp[3]` = buy2 | `dp[3]` = buy2 |
| `dp[4]` = sell2 | `dp[4]` = sell2 |
| — | ... 泛化到 `dp[2k-1]`, `dp[2k]` |

当 `k = 2` 时，188 题代码完全退化为 123 题的 O(k) 优化版本。

---

### 3. 变量设计与迭代推演

| 变量 | 含义 | 初始值 |
|------|------|--------|
| `n` | 数组长度 | `len(prices)` |
| `dp` | 长度为 `2k+1` 的一维数组 | 奇数位 = `-prices[0]`，其余 = 0 |

以 `k = 2, prices = [3,2,6,5,0,3]` 为例（等价于 123 题示例）：

| 天 | 价格 | dp[1] buy1 | dp[2] sell1 | dp[3] buy2 | dp[4] sell2 |
|----|------|-----------|-------------|-----------|-------------|
| 0 | 3 | **-3** | 0 | **-3** | 0 |
| 1 | 2 | **-2** | 0 | **-2** | 0 |
| 2 | 6 | -2 | **4** | -2 | 4 |
| 3 | 5 | -2 | 4 | **-1** | 4 |
| 4 | 0 | **0** | 4 | **4** | 4 |
| 5 | 3 | 0 | 4 | 4 | **7** |

返回 `dp[-1] = dp[4] = 7`。✅

路径：`buy(天1,2元) → sell(天2,6元) → buy(天4,0元) → sell(天5,3元)`，利润 = 4 + 3 = 7。

---

### 4. 关键边界：k 过大时的优化

当 `k ≥ n // 2` 时，交易次数不再构成限制（因为一次完整交易至少需要 2 天），问题退化为 [122. 买卖股票的最佳时机 II](./题目目录/0122-best-time-to-buy-and-sell-stock-ii)（不限交易次数，贪心即可）。

```python
# 可选的剪枝优化（本题代码未显式处理，但 O(k) 空间在 k 极大时可能成为瓶颈）
if k >= n // 2:
    # 退化为无限次交易，贪心累加所有上涨段
    return sum(max(0, prices[i] - prices[i-1]) for i in range(1, n))
```

未加此剪枝时，当 `k` 远大于 `n`，DP 数组大小 $O(k)$ 可能造成内存浪费，但算法逻辑仍然正确。

### 6. 复杂度分析

- **时间复杂度**：$O(n \times k)$，每天对每笔交易执行常数次操作。当 $k \ge n/2$ 时退化为 $O(n)$。

- **空间复杂度**：$O(k)$（长度为 `2k+1` 的一维数组）。相比朴素二维 DP 的 $O(n \times k)$，空间优化显著。
