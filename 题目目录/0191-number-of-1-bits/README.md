## [191. 位1的个数](https://leetcode.cn/problems/number-of-1-bits/)

### 简单

编写一个函数，输入是一个无符号整数（以二进制串的形式），返回其二进制表达式中数字位数为 `1` 的个数（也被称为**汉明重量**）。

**示例 1：**

<pre><strong>输入：</strong>n = 00000000000000000000000000001011
<strong>输出：</strong>3
<strong>解释：</strong>输入的二进制串 <strong>00000000000000000000000000001011</strong> 中，共有三位为 '1'。</pre>

**示例 2：**

<pre><strong>输入：</strong>n = 00000000000000000000000010000000
<strong>输出：</strong>1
<strong>解释：</strong>输入的二进制串 <strong>00000000000000000000000010000000</strong> 中，共有一位为 '1'。</pre>

**示例 3：**

<pre><strong>输入：</strong>n = 11111111111111111111111111111101
<strong>输出：</strong>31
<strong>解释：</strong>输入的二进制串 <strong>11111111111111111111111111111101</strong> 中，共有 31 位为 '1'。</pre>

**提示：**

- 输入必须是长度为 32 的二进制串。

**进阶：**

- 如果多次调用这个函数，你将如何优化你的算法？

---

## 题解：`n & (n - 1)` 消最低位 1

### 1. 核心思路：每次消除一个 1

统计二进制中 1 的个数，最朴素的做法是逐位检查 32 次。但有一个更巧妙的位运算技巧：**`n & (n - 1)` 会将 `n` 的二进制表示中最右边的 `1` 变为 `0`**。

```
n      = 101100  (二进制)
n-1    = 101011  (n 的最右 1 变 0，其右侧全变 1)
n&(n-1)= 101000  → 最右边的 1 被消除了！
```

直观理解：`n - 1` 会把 `n` 最右边那个 `1` 变成 `0`，同时把该位右侧所有的 `0` 变成 `1`。再与原数做 `&` 运算，那个 `1` 以及其右侧所有位都被清零。

**关键洞察**：1 的个数就是能执行多少次 `n & (n - 1)` 操作直到 `n` 变为 `0`。

---

### 2. 执行逻辑的详细拆解

#### A. 初始化

```python
ans = 0  # 计数器，记录 1 的个数
```

#### B. 主循环

```python
while n > 0:
    n = n & (n - 1)  # 消除最右边的 1
    ans += 1          # 计数 +1
```

每次循环消除一个 `1`，循环次数恰好等于二进制中 `1` 的个数。当 `n` 变为 `0`（即所有 `1` 都已被消除）时，循环终止。

#### C. 返回结果

```python
return ans
```

---

### 3. 逻辑亮点

- **O(k) 而非 O(32)**：循环次数等于 1 的个数 k，而非固定的 32 次。在 1 的个数较少时（如 `n = 0b10000000` 只有 1 个 1），只需循环 1 次，远快于逐位遍历。

- **无分支判断**：不需要 `if n & 1` 然后再右移，只需一个 `n & (n - 1)` 即可消除最右 1，代码极为简洁。

- **无符号整数处理**：Python 的 `int` 是任意精度整数，代码中用 `n > 0` 而非 `n != 0` 判断，因为题目保证输入是无符号整数（非负）。若需处理负数（有符号整数），应改用 `while n:` 并配合掩码。

---

### 4. 复杂度分析

- **时间复杂度**：$O(k)$，其中 $k$ 为二进制中 `1` 的个数。最坏情况（全 1）下为 $O(32) = O(1)$。

- **空间复杂度**：$O(1)$，仅使用常数变量。

---

### 5. 对比其他解法

| 方法 | 思路 | 时间复杂度 |
|------|------|-----------|
| **逐位检查** | `for i in range(32): ans += (n >> i) & 1` | $O(32)$，固定 32 次 |
| **右移统计** | `while n: ans += n & 1; n >>= 1` | $O(\log n)$，需遍历所有位直到最高位 1 |
| **`n & (n - 1)`** | 每次消除最右 1（本解法） | $O(k)$，k = 1 的个数，最优 |
| **库函数** | `bin(n).count('1')` | $O(\log n)$，非算法解 |
| **分治法** | 分组累加 → `popcount` 硬件指令 | $O(1)$ 硬件加速 |

**`n & (n - 1)` 技巧也是判断一个数是否为 2 的幂的关键**：若 `n > 0 and n & (n - 1) == 0`，则 `n` 的二进制中只有一个 1，即 `n` 是 2 的幂。这是位运算中最高频的模板之一。

---

### 代码回顾

```python
class Solution:
    def hammingWeight(self, n: int) -> int:
        ans = 0
        while n > 0:
            n = n & (n - 1)
            ans += 1
        return ans
```

> **延伸思考**：如果此题改成多次调用，可以预计算 0~65535（16 位）所有数的汉明重量存入数组，然后每次查询时将 32 位整数拆为高 16 位和低 16 位，查表相加即可。这就是经典的**空间换时间查表法**。
