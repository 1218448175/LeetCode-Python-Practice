## [201. 数字范围按位与](https://leetcode.cn/problems/bitwise-and-of-numbers-range/)

### 中等

给你两个整数 `left` 和 `right`，表示区间 `[left, right]`，返回此区间内所有数字按位与的结果（包含 `left`、`right` 端点）。

**示例 1：**

<pre><strong>输入：</strong>left = 5, right = 7
<strong>输出：</strong>4
<strong>解释：</strong>5 & 6 & 7 = 4
  5 → 101
  6 → 110
  7 → 111
  按位与 → 100 = 4
</pre>

**示例 2：**

<pre><strong>输入：</strong>left = 0, right = 0
<strong>输出：</strong>0
</pre>

**示例 3：**

<pre><strong>输入：</strong>left = 1, right = 2147483647
<strong>输出：</strong>0
</pre>

**提示：**

- `0 <= left <= right <= 2^31 - 1`

---

## 题解：公共前缀法 — 利用异或定位首个差异位

### 1. 核心思路：只有"公共前缀"能存活

对区间 `[left, right]` 内所有数做按位与，结果是什么？

逐位考虑：**某一位上，只要区间内存在一个数该位为 0，最终结果该位就是 0**。连续区间中，数字是递增的，低位会频繁地在 0 和 1 之间翻转。只有**高位**可能在区间内全程保持不变——这些位就是 `left` 和 `right` 的二进制"公共前缀"。

```
left  = 5 → 0000 0101
right = 7 → 0000 0111
            ^^^^^^      ← 高 5 位完全相同（公共前缀）
                  ^^    ← 低 2 位不同，区间内必然出现过 0，按位与得 0

结果 = 0000 0100 = 4 ✅
```

> **直觉理解**：连续数字的范围中，进位会导致低位不断翻转。例如从 5(101) 到 7(111)，最低两位经历了 01→10→11，其中第 0 位出现了 1→0→1，第 1 位出现了 0→1→1。只要某位出现过 0，按位与后就是 0。只有公共前缀部分从头到尾没变过，才能保留下来。

---

### 2. 解法推导：三种等价写法

#### 方法一：右移找公共前缀（最直观）

不断将 `left` 和 `right` 右移，直到两者相等——此时剩余的就是公共前缀。记录右移次数，最后左移回去。

```python
def rangeBitwiseAnd(left: int, right: int) -> int:
    shift = 0
    while left < right:
        left >>= 1
        right >>= 1
        shift += 1
    return left << shift
```

#### 方法二：Brian Kernighan 消末位 1

不断消去 `right` 最低位的 1，直到 `right <= left`。因为 `right` 低位的变化是结果归零的根本原因，逐次抹掉最低位 1 等价于将"不稳定的低位"清零。

```python
def rangeBitwiseAnd(left: int, right: int) -> int:
    while left < right:
        right &= (right - 1)   # 抹去 right 最低位的 1
    return right
```

#### 方法三：异或定位差异位（本解使用，最巧妙）

```python
class Solution:
    def rangeBitwiseAnd(self, left: int, right: int) -> int:
        m = (left ^ right).bit_length()
        return left & ~((1 << m) - 1)
```

`left ^ right` 的结果中，为 1 的位就是 `left` 和 `right` 不同的位。`.bit_length()` 返回异或结果的二进制长度，即**最高差异位的位置 + 1**。

- `(1 << m) - 1` 构造 m 个 1（低 m 位全 1 的掩码）
- `~((1 << m) - 1)` 取反后，低 m 位为 0，高位全 1
- `left & 掩码` — 保留公共前缀，将低 m 位清零

> 三种方法本质相同：**找到 left 和 right 第一个不同的位，将之后所有位置零**。

---

### 3. 执行逻辑的详细拆解

以 `left = 5, right = 7` 为例：

```
left  = 5  → 0000 0101
right = 7  → 0000 0111

left ^ right = 0000 0101 ^ 0000 0111
             = 0000 0010  → 十进制 2

.bit_length() = 2   (二进制 "10" 占 2 位)

m = 2

(1 << m)     = 1 << 2 = 4  → 0000 0100
(1 << m) - 1 = 3           → 0000 0011  (低 2 位全 1)

~(掩码)       = ~0000 0011
              = 1111 1100  (低 2 位为 0，其余为 1)

left & 掩码   = 0000 0101 & 1111 1100
              = 0000 0100 = 4 ✅
```

再以 `left = 10, right = 15` 为例：

```
left  = 10 → 0000 1010
right = 15 → 0000 1111

left ^ right = 0000 0101 → bit_length = 3
(bit 0 不同，bit 1 不同，bit 2 相同…最高差异位是 bit 2，所以 bit_length = 3)

m = 3, 掩码 = 低 3 位清零 → 保留 bit 3 及以上

10 & ~((1<<3)-1) = 1010 & 1000 = 1000 = 8 ✅

验证：10 & 11 & 12 & 13 & 14 & 15
  1010 & 1011 & 1100 & 1101 & 1110 & 1111
= 1000 = 8 ✅
```

---

### 4. 逻辑亮点

- **一行定位差异边界**：`(left ^ right).bit_length()` 直接给出"从哪一位开始不同"，无需循环右移。Python 内置方法 `int.bit_length()` 底层是 O(1) 操作。

- **掩码清零，一步到位**：`left & ~((1 << m) - 1)` 用位运算一次性将不稳定低位全部清零，比循环 `right &= right - 1` 更简洁。

- **核心洞察的普适性**："区间按位与 = 公共前缀"这个规律，本质是因为连续整数在二进制下低位周期性翻转。理解这一点后，三种写法（右移、消末位 1、异或掩码）变得一目了然。

- **O(1) 空间**：仅使用一个临时变量 `m` 辅助计算掩码，没有数组或递归。

---

### 5. 复杂度分析

- **时间复杂度**：O(1)。异或、`.bit_length()`、移位和按位与都是 O(1) 的位运算操作，不依赖输入规模。

- **空间复杂度**：O(1)。仅使用常数个变量。

---

### 6. 对比其他解法

| 方法 | 时间复杂度 | 空间复杂度 | 代码行数 | 核心操作 |
|------|-----------|-----------|---------|---------|
| **异或掩码法（本解）** | O(1) | O(1) | 2 行 | `bit_length` + 掩码 |
| 右移公共前缀 | O(log n) | O(1) | 4 行 | `while left < right` 右移 |
| Brian Kernighan | O(log n) | O(1) | 3 行 | `right &= right - 1` |

> 三种方法在 32 位整数范围内实际效率相差无几（最多 32 次循环），异或掩码法胜在代码最简洁、无显式循环。

### 代码回顾

```python
class Solution:
    def rangeBitwiseAnd(self, left: int, right: int) -> int:
        m = (left ^ right).bit_length()
        return left & ~((1 << m) - 1)
```

> **一句总结**：区间内所有数的按位与结果 = `left` 和 `right` 的二进制公共前缀。用异或定位首个差异位，掩码一步清零所有不稳定的低位，O(1) 时间完成。
