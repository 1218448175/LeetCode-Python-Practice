## [230. 二叉搜索树中第 K 小的元素](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/)

### 中等

给定一个二叉搜索树的根节点 `root` ，和一个整数 `k` ，请你设计一个算法查找其中第 `k` 小的元素（`k` 从 1 开始计数）。

## 题解：基于栈的迭代中序遍历

### 1. 核心思路：利用 BST 的有序性提前终止

二叉搜索树（BST）的中序遍历结果是严格递增的。要找到第 $k$ 小的元素，最有效的方法就是按照**中序遍历**的顺序进行计数。

- **性质应用**：中序遍历访问节点的顺序即为从小到大的顺序。

- **迭代法（显式栈）**：相比于递归，使用迭代法配合栈可以更灵活地控制遍历过程。一旦找到第 $k$ 个元素，我们可以**立即返回结果并停止遍历**，从而节省不必要的开销。

---

### 2. 执行逻辑的详细拆解

#### A. 初始化

- 创建一个空栈 `stack`，用于模拟递归时的函数调用栈。

- 使用 `root` 指针作为当前遍历的控制变量。

#### B. 迭代过程

1. **“一路向左”**：
   
   - 通过 `while root` 将当前节点及其所有左孩子压入栈中。这样栈顶永远是当前子树中最小的元素。

2. **出队与计数**：
   
   - 从栈中弹出（`pop`）节点，这代表我们访问了当前“最左下”的节点。
   
   - 每访问一个节点，执行 `k -= 1`。

3. **判定退出**：
   
   - 如果 `k == 0`，说明当前弹出的节点正是我们要找的第 $k$ 小元素，直接返回 `root.val`。

4. **转向右子树**：
   
   - 如果还没找到，令 `root = root.right`，继续对右子树进行上述同样的“向左深入”操作。

---

### 3. 与递归法对比（可选思路）

递归法（如 `inorder(root)` 存入列表再取索引）虽然代码简洁，但在处理大型树或 $k$ 较小时不够高效，因为它通常会遍历整棵树。迭代法能保证在处理完第 $k$ 个节点后准时“刹车”。

---

### 4. 复杂度分析

- **时间复杂度**：$O(H + k)$。其中 $H$ 是树的高度。我们需要先花 $O(H)$ 时间到达最左下的叶子，然后经过 $k$ 个节点的访问。

- **空间复杂度**：$O(H)$。栈中最多存储 $H$ 个节点。在最坏情况下（树呈链状），空间复杂度为 $O(n)$；平衡二叉树则为 $O(\log n)$。

---

### 5. 代码回顾

```py
class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        stack = []

        # 只要指针不为空或栈内还有节点，就继续遍历
        while root or stack:
            # 1. 尽可能地向左深入，将路径上的节点入栈
            while root:
                stack.append(root)
                root = root.left

            # 2. 弹出当前最小的节点
            root = stack.pop()

            # 3. 计数
            k -= 1
            if k == 0:
                return root.val

            # 4. 转向右子树，寻找下一个较大的节点
            root = root.right
```
