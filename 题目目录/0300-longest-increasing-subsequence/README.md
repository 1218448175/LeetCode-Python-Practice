## [300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/)

### 中等

给你一个整数数组 `nums`，找到其中最长严格递增子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。子序列不要求连续。

<p><strong>示例 1:</strong></p>
<pre><strong>输入:</strong> nums = [10,9,2,5,3,7,101,18]
<strong>输出:</strong> 4
<strong>解释:</strong> 最长递增子序列是 [2,3,7,101]，因此长度为 4。
</pre>

<p><strong>示例 2:</strong></p>
<pre><strong>输入:</strong> nums = [0,1,0,3,2,3]
<strong>输出:</strong> 4
</pre>

<p><strong>示例 3:</strong></p>
<pre><strong>输入:</strong> nums = [7,7,7,7,7,7,7]
<strong>输出:</strong> 1
</pre>

---

## 题解：动态规划 — 线性 DP（O(n²)）

### 1. 核心思路：以每个元素为结尾的最长递增子序列

这道题是经典的**最长递增子序列（LIS）**问题。定义 `dp[i]` 表示：**以 `nums[i]` 结尾**的最长递增子序列的长度。

**状态转移**：对于位置 `i`，向前扫描所有 `j < i`：

- 如果 `nums[i] > nums[j]`，说明 `nums[i]` 可以接在以 `nums[j]` 结尾的子序列后面
- 因此 `dp[i] = max(dp[i], dp[j])`，取所有可接续方案中的最大值

最后，`dp[i] += 1`（加上当前元素自身）。

$$dp[i] = \max_{j < i,\ nums[j] < nums[i]}(dp[j]) + 1$$

**边界条件**：每个元素自身构成长度为 1 的递增子序列，`dp[i]` 初始为 0，最后 `+1` 后至少为 1。

---

### 2. 与贪心+二分（O(n log n)）的对比

| 对比维度 | DP（本题解法） | 贪心 + 二分 |
|---------|---------------|------------|
| 时间复杂度 | O(n²) | O(n log n) |
| 空间复杂度 | O(n) | O(n) |
| 核心思想 | 以每个位置结尾的 LIS | 维护各长度 LIS 的最小结尾值 |
| 能否还原具体子序列 | ✅ 容易（记录前驱索引） | ⚠️ `tail` 数组不直接对应子序列 |
| 适用场景 | n ≤ 2500，代码简洁直观 | n 较大时的最优解 |

本题 `n ≤ 2500`，O(n²) DP 完全可行，且代码更直观。

---

### 3. 变量设计与迭代推演

| 变量 | 含义 | 初始值 |
|------|------|--------|
| `n` | 数组长度 | `len(nums)` |
| `dp` | 一维数组，`dp[i]` 表示以 `nums[i]` 结尾的 LIS 长度 | 全 0，每轮 `+1` 后至少为 1 |

以 `nums = [10, 9, 2, 5, 3, 7, 101, 18]` 为例：

| i | nums[i] | j 扫描 | dp[i] 更新过程 | 最终 dp[i] |
|---|---------|--------|---------------|-----------|
| 0 | 10 | 无 | dp[0]=0 → +1 | 1 |
| 1 | 9 | 10: 9<10 ✗ | dp[1]=0 → +1 | 1 |
| 2 | 2 | 10,9: 都 ✗ | dp[2]=0 → +1 | 1 |
| 3 | 5 | 2: 5>2 ✓ dp[3]=max(0,1)=1 | dp[3]=1 → +1 | 2 |
| 4 | 3 | 2: 3>2 ✓ dp[4]=1; 5: 3<5 ✗ | dp[4]=1 → +1 | 2 |
| 5 | 7 | 2: dp[5]=1; 5: dp[5]=max(1,2)=2; 3: dp[5]=max(2,2)=2 | dp[5]=2 → +1 | 3 |
| 6 | 101 | 所有 j 的 nums[j] < 101, max dp[j]=3 | dp[6]=3 → +1 | 4 |
| 7 | 18 | 2:1; 5:2; 3:2; 7:3; 101:✗ → max=3 | dp[7]=3 → +1 | 4 |

最终 `max(dp) = 4`，对应子序列 `[2, 5, 7, 101]` 或 `[2, 3, 7, 101]`。

---

### 4. 代码逐行解读

```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [0 for _ in range(n)]          # dp[i] 初始为 0
        for i in range(n):                   # 遍历每个位置 i
            for j in range(i):               # 向前扫描所有 j < i
                if nums[i] > nums[j]:        # 可以接在 nums[j] 后面
                    dp[i] = max(dp[i], dp[j]) # 取最大的 dp[j]
            dp[i] += 1                       # 加上当前元素自身
        return max(dp)                       # 返回全局最大值
```

- 外层循环 `i` 从 0 到 n-1，逐个计算以 `nums[i]` 结尾的 LIS
- 内层循环 `j` 扫描 `i` 之前所有位置，找到可以接续的最优方案
- `dp[i] += 1` 统一处理，即使没有可接续的 `j`（dp[i]=0），加 1 后也表示单个元素
- 最终返回 `max(dp)` 而非 `dp[n-1]`，因为最长子序列不一定以最后一个元素结尾

---

### 5. 复杂度分析

- **时间复杂度**：$O(n^2)$，其中 $n$ 为数组长度。两层嵌套循环，每对 `(j, i)` 访问一次。

- **空间复杂度**：$O(n)$。仅使用一个长度为 $n$ 的 `dp` 数组。
