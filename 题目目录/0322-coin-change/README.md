## [322. 零钱兑换](https://leetcode.cn/problems/coin-change/)

### 中等

给你一个整数数组 `coins`，表示不同面额的硬币；以及一个整数 `amount`，表示总金额。

计算并返回可以凑成总金额所需的 **最少的硬币个数**。如果没有任何一种硬币组合能组成总金额，返回 `-1`。

你可以认为每种硬币的数量是无限的。

<p><strong>示例 1:</strong></p>
<pre><strong>输入:</strong> coins = [1, 2, 5], amount = 11
<strong>输出:</strong> 3
<strong>解释:</strong> 11 = 5 + 5 + 1
</pre>

<p><strong>示例 2:</strong></p>
<pre><strong>输入:</strong> coins = [2], amount = 3
<strong>输出:</strong> -1
</pre>

<p><strong>示例 3:</strong></p>
<pre><strong>输入:</strong> coins = [1], amount = 0
<strong>输出:</strong> 0
</pre>

---

## 题解：动态规划 — 完全背包（二维递推）

### 1. 核心思路：每种硬币无限使用的完全背包

这道题是经典的**完全背包问题**（每种物品可选无限次），目标不是最大价值，而是**最少硬币数**。

定义 `f[i][c]` 表示：使用前 `i` 种硬币，凑出金额 `c` 所需的最少硬币个数。

**状态转移**：对于第 `i` 种硬币（面额为 `x`），金额 `c` 有两个选择：

- **不用第 `i` 种硬币**：`f[i+1][c] = f[i][c]`
- **用一枚第 `i` 种硬币**：`f[i+1][c] = f[i+1][c-x] + 1`（注意是 `i+1` 而非 `i`，表示同一硬币可重复使用）

取两者的最小值：

$$f[i+1][c] = \begin{cases} f[i][c] & c < x \\ \min(f[i][c],\ f[i+1][c-x] + 1) & c \ge x \end{cases}$$

**边界条件**：`f[0][0] = 0`（0 种硬币凑 0 元需 0 枚），其余初始化为 `inf`（不可达）。

---

### 2. 与经典 0/1 背包的关键区别

| 对比维度 | 0/1 背包 | 完全背包（本题） |
|---------|----------|----------------|
| 物品使用次数 | 每种最多用 1 次 | 每种可用无限次 |
| 递推公式 | `f[i+1][c] = min(f[i][c], f[i][c-x] + 1)` | `f[i+1][c] = min(f[i][c], f[i+1][c-x] + 1)` |
| 正排/逆排 | 容量逆序遍历（一维优化时） | 容量正序遍历（一维优化时） |

关键差异在于第二个参数：0/1 背包用 `f[i][c-x]`（上一行），完全背包用 `f[i+1][c-x]`（当前行），因为当前硬币可以无限使用，需要考虑"已经用过当前硬币"的状态。

---

### 3. 变量设计与迭代推演

| 变量 | 含义 | 初始值 |
|------|------|--------|
| `n` | 硬币种类数 | `len(coins)` |
| `f` | DP 二维数组，`f[i][c]` 表示前 `i` 种硬币凑 `c` 元的最少枚数 | `f[0][0] = 0`，其余 `inf` |
| `inf` | 不可达标记 | `float('inf')` |

以 `coins = [1, 2, 5], amount = 5` 为例（简化版推演）：

| i | coin | c=0 | c=1 | c=2 | c=3 | c=4 | c=5 |
|---|------|-----|-----|-----|-----|-----|-----|
| 0 | -    | 0   | inf | inf | inf | inf | inf |
| 1 | 1    | 0   | 1   | 2   | 3   | 4   | 5   |
| 2 | 2    | 0   | 1   | 1   | 2   | 2   | 3   |
| 3 | 5    | 0   | 1   | 1   | 2   | 2   | 1   |

- 第 1 行（只用面额 1）：`f[1][c] = c`（全用 1 元硬币）
- 第 2 行（加入面额 2）：`c=2` 时 `min(f[1][2], f[2][0]+1) = min(2, 1) = 1`
- 第 3 行（加入面额 5）：`c=5` 时 `min(f[2][5], f[3][0]+1) = min(3, 1) = 1`

最终 `f[3][5] = 1`（一枚 5 元硬币即可）。

---

### 4. 一维空间优化思路

观察递推公式，`f[i+1][c]` 只依赖 `f[i][c]`（正上方）和 `f[i+1][c-x]`（同行左侧）。因此可以压缩为一维：

```python
dp = [inf] * (amount + 1)
dp[0] = 0
for x in coins:
    for c in range(x, amount + 1):
        dp[c] = min(dp[c], dp[c - x] + 1)
```

- 内层循环**正序**遍历（因为依赖当前行的左侧值）
- 空间复杂度从 $O(n \times amount)$ 降至 $O(amount)$

---

### 5. 复杂度分析

- **时间复杂度**：$O(n \times amount)$，其中 $n$ 为硬币种类数。外层遍历每种硬币，内层遍历每个金额，不可省略。

- **空间复杂度**：
  - 二维版本：$O(n \times amount)$
  - 一维优化版本：$O(amount)$
