<h2><a href="https://leetcode.cn/problems/ipo">502. IPO</a></h2>
<h3>困难</h3>
<hr>
<p>假设力扣即将开始 <strong>IPO</strong>。为了以更高的价格将股票卖给风险投资公司，力扣希望在 IPO 之前开展一些项目以增加其资本。由于资源有限，它只能在 IPO 之前完成<strong>最多 <code>k</code> 个</strong>不同的项目。</p>
<p>给定 <code>n</code> 个项目，对于每个项目 <code>i</code>，都有一个纯利润 <code>profits[i]</code> 和启动该项目所需的最小资本 <code>capital[i]</code>。</p>
<p>初始资本为 <code>w</code>。完成一个项目后，获得的利润将<strong>添加到总资本中</strong>，从而可以启动更多项目。</p>
<p>你的目标是从给定项目中选择<strong>最多 <code>k</code></strong> 个不同项目，使得最终资本最大化，并返回最终可获得的最多资本。</p>
<p>&nbsp;</p>
<p><strong>示例 1：</strong></p>
<pre><strong>输入：</strong>k = 2, w = 0, profits = [1,2,3], capital = [0,1,1]
<strong>输出：</strong>4
<strong>解释：</strong>
初始资本为 0，只能启动 capital 为 0 的项目（0 号，利润 1）。
完成 0 号项目后，资本变为 1。
此时可启动 1 号或 2 号项目（capital 均为 1），选择利润最大的 2 号（利润 3）。
最终资本 = 0 + 1 + 3 = 4。
</pre>

<p><strong>示例 2：</strong></p>
<pre><strong>输入：</strong>k = 3, w = 0, profits = [1,2,3], capital = [0,1,2]
<strong>输出：</strong>6
</pre>

---

### 解题思路

本题的核心是 **贪心 + 大根堆**。

直观贪心策略：在每一轮中，从所有当前资本足够启动的项目里，选择**利润最大**的那个来执行。因为资本只会增加（不会消耗，只是门槛），每次选利润最大的项目总是最优的。

具体做法：
1. 将所有项目按 `capital`（所需资本）从小到大排序。
2. 用一个指针扫描排序后的项目列表，每次将 `capital <= w`（当前资本足够启动）的项目利润压入大根堆。
3. 从大根堆中弹出利润最大的项目，将其利润加入 `w`。
4. 重复最多 `k` 次。如果某轮堆为空（无可启动项目），提前结束。

此外，代码中包含一个巧妙的**剪枝优化**：如果初始资本 `w` 已经大于等于所有项目的最大资本要求，那么所有项目都可直接启动，只需选取利润最大的 `k` 个项目即可，无需走堆的流程。

### 算法步骤

- 剪枝判断：若 `w >= max(capital)`，直接返回 `w + sum(前 k 大 profits)`
- 构建 `(profit, capital)` 列表并按 `capital` 升序排序
- 初始化大根堆 `heap`（Python 的 `heapq` 是小根堆，所以存储负利润）
- 初始化指针 `curr = 0`
- 循环最多 `k` 次：
  - 将所有 `capital <= w` 的项目利润（取负）压入堆中，`curr` 指针右移
  - 若堆非空，弹出最大利润（取负恢复正值）加入 `w`
  - 若堆为空，`break`（没有更多可启动的项目）
- 返回 `w`

### 复杂度分析

- **时间复杂度**：O(n log n)。排序 O(n log n)，每个项目最多进堆一次、出堆一次，堆操作 O(log n)，总 O(n log n)。
- **空间复杂度**：O(n)。排序数组和堆各占 O(n) 空间。
