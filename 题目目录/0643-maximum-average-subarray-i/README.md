## [643. 子数组最大平均数 I](https://leetcode.cn/problems/maximum-average-subarray-i/)

### 简单

给你一个由 `n` 个元素组成的整数数组 `nums` 和一个整数 `k`，请你找出平均数最大且长度为 `k` 的连续子数组，并输出该最大平均数。

任何误差小于 $10^{-5}$ 的答案都将被视为正确答案。

**示例 1：**
<pre><strong>输入：</strong>nums = [1,12,-5,-6,50,3], k = 4
<strong>输出：</strong>12.75
<strong>解释：</strong>最大平均数 (12-5-6+50)/4 = 51/4 = 12.75
</pre>

**示例 2：**
<pre><strong>输入：</strong>nums = [5], k = 1
<strong>输出：</strong>5.00000
</pre>

---

## 题解：定长滑动窗口（单循环风格）

### 1. 问题转化：最大平均数 → 最大和

由于所有子数组的长度固定为 `k`，**和最大的子数组，其平均数也最大**：

$$\max\left(\frac{\text{window\_sum}}{k}\right) = \frac{\max(\text{window\_sum})}{k}$$

因此核心任务是：求长度为 `k` 的所有子数组的**最大和**。

---

### 2. 核心思路：三步循环法

你的代码延续了"单循环三步法"的滑动窗口风格，与 [1456. 定长子串中元音的最大数目](../1456-maximum-number-of-vowels-in-a-substring-of-given-length/) 一脉相承：

```python
ans = -inf
window_cnt = 0
n = len(nums)
for i in range(n):              # 枚举窗口右端点 i
    left = i - k + 1            # 计算窗口左端点
    window_cnt += nums[i]       # 1. 右端点进入窗口

    if left < 0:                # 窗口长度不足 k → 继续扩展
        continue

    ans = max(ans, window_cnt / k)  # 2. 更新答案

    window_cnt -= nums[left]    # 3. 左端点离开窗口（为下一次滑动做准备）
return ans
```

**执行轨迹（nums = [1, 12, -5, -6, 50, 3], k = 4）：**

| 步 | i | nums[i] | left | 窗口 | window_cnt | ans | 动作 |
|----|---|---------|------|------|------------|-----|------|
| 0 | 0 | 1 | -3 (未形成) | — | 1 | -∞ | continue |
| 1 | 1 | 12 | -2 (未形成) | — | 13 | -∞ | continue |
| 2 | 2 | -5 | -1 (未形成) | — | 8 | -∞ | continue |
| 3 | 3 | -6 | 0 | [1,12,-5,-6] | 2 | 0.5 | 移除 nums[0]=1 → cnt=1 |
| 4 | 4 | 50 | 1 | [12,-5,-6,50] | 51 | 12.75 | 移除 nums[1]=12 → cnt=39 |
| 5 | 5 | 3 | 2 | [-5,-6,50,3] | 42 | 12.75 | 移除 nums[2]=-5 → cnt=47 |

最终答案：**12.75**（窗口 [12, -5, -6, 50] 的和为 51，平均值 12.75）。

---

### 3. 亮点分析

#### 3.1 统一的单循环结构

与传统"先算第一个窗口再循环滑动"的写法相比，你的代码将**窗口形成前**和**窗口滑动后**统一在一个循环中处理：

```python
if left < 0:       # 尚未形成完整窗口
    continue        # 只累积，不判定，不移除
```

窗口形成前（前 `k-1` 个元素）只执行 `window_cnt += nums[i]` 然后跳过，相当于在悄悄"预热"窗口。窗口一旦形成（`left >= 0`），后续每个迭代都是完整的"进入→判定→退出"三步。

#### 3.2 安全初始化：`ans = -inf`

```python
ans = -inf
```

由于 `nums[i]` 可能为负数（题目约束 $-10^4 \leq nums[i] \leq 10^4$），用 `-inf` 而非 `0` 初始化 `ans`，确保任何合法窗口的平均值都能正确更新 `ans`。

#### 3.3 可商榷之处：循环内做除法

```python
ans = max(ans, window_cnt / k)   # 每次迭代都做浮点除法
```

更常见的做法是循环内比较**和**，循环外只做**一次除法**：

```python
# 更优写法
ans = max(ans, window_cnt)       # 比较整数和
return ans / k                    # 最后一次性除法
```

这样做有两个好处：
1. **性能**：避免每次迭代的浮点运算开销（虽然本题 `n` 不大，养成习惯更好）
2. **精度**：减少多次除法引入的累积浮点误差

不过你当前的写法在正确性上没有瑕疵，只是性能上略微吃亏。

---

### 4. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素被"进入窗口"和"离开窗口"各处理一次，单次遍历完成。
- **空间复杂度**：$O(1)$，仅使用 `ans`、`window_cnt`、`left`、`n` 四个额外变量。

---

### 延伸思考

- 本题和 [1456. 定长子串中元音的最大数目](../1456-maximum-number-of-vowels-in-a-substring-of-given-length/) 同为**定长滑动窗口**模板题，核心结构完全一致：单循环 → left < 0 跳过 → 更新答案 → 移除左端点。
- 如果改为**不定长**求最大平均数（无固定 $k$），则需要二分答案 + 前缀和判定，难度会跃升至中等以上。
- 前缀和解法也能 $O(n)$ 通过本题，但需要 $O(n)$ 额外空间，滑动窗口的空间优势更明显。
