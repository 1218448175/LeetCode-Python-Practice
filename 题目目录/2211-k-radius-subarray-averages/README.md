## [2211. 半径为 k 的子数组平均值](https://leetcode.cn/problems/k-radius-subarray-averages/)

### 中等

给你一个下标从 **0** 开始的数组 `nums`，数组中有 `n` 个整数，另给你一个整数 `k`。

**半径为 k 的子数组平均值** 是指：`nums` 中一个以下标 `i` 为中心且半径为 `k` 的子数组中所有元素的平均值，即下标范围 `[i - k, i + k]` 内所有元素的平均值。如果下标 `i` 前或后不足 `k` 个元素，则返回 `-1`。

平均值采用**截断式整数除法**（向下取整）。

**示例 1：**
<pre><strong>输入：</strong>nums = [7,4,3,9,1,8,5,2,6], k = 3
<strong>输出：</strong>[-1,-1,-1,5,4,4,-1,-1,-1]
<strong>解释：</strong>
- 下标 3 处：窗口 [7,4,3,9,1,8,5] 的和为 37，平均值为 37 // 7 = 5
- 下标 4 处：窗口 [4,3,9,1,8,5,2] 的和为 32，平均值为 32 // 7 = 4
- 下标 5 处：窗口 [3,9,1,8,5,2,6] 的和为 34，平均值为 34 // 7 = 4
</pre>

**示例 2：**
<pre><strong>输入：</strong>nums = [100000], k = 0
<strong>输出：</strong>[100000]
</pre>

**示例 3：**
<pre><strong>输入：</strong>nums = [8], k = 100000
<strong>输出：</strong>[-1]
</pre>

---

## 题解：定长滑动窗口

### 1. 核心思路

窗口大小固定为 `2k + 1`，只有当 `2k + 1 ≤ n` 时才有有效的中心位置。有效的中心下标范围是 `[k, n - k - 1]`（共 `n - 2k` 个位置）。

代码采用了巧妙的"**预留一位**"的滑动窗口策略：

1. 预先计算前 `2k` 个元素的和（比完整窗口少一个右边界元素）
2. 每次迭代时，先加上右边界新元素 → 窗口扩展为完整的 `2k + 1` 个元素 → 计算平均值
3. 再减去左边界元素 → 窗口收缩回 `2k` 个元素，为下一次滑动做准备

```python
ans = [-1 for _ in range(n)]
total = sum(nums[0:2 * k])          # 预留一位：先算前 2k 个元素的和
for i in range(k, n - k):           # 枚举窗口中心 i
    total += nums[i + k]            # 1. 右边界进入 → 窗口扩展为 2k+1
    ans[i] = total // (2 * k + 1)   # 2. 计算当前窗口平均值
    total -= nums[i - k]            # 3. 左边界离开 → 窗口收缩为 2k，准备右移
return ans
```

---

### 2. 执行轨迹

以 `nums = [7, 4, 3, 9, 1, 8, 5, 2, 6], k = 3` 为例：

| 步 | i | 加入 nums[i+k] | total | ans[i] | 移除 nums[i-k] | total（移除后） |
|----|---|---------------|-------|--------|---------------|----------------|
| — | — | — | 32 (初始：前6个) | — | — | 32 |
| 0 | 3 | nums[6]=5 | 37 | 37//7=5 | nums[0]=7 | 30 |
| 1 | 4 | nums[7]=2 | 32 | 32//7=4 | nums[1]=4 | 28 |
| 2 | 5 | nums[8]=6 | 34 | 34//7=4 | nums[2]=3 | 31 |

最终结果：`[-1, -1, -1, 5, 4, 4, -1, -1, -1]`。

---

### 3. 关键细节

#### 3.1 预留一位的设计

与传统滑动窗口（先算完整窗口再循环滑动）不同，本代码通过"预留一位"将窗口形成与滑动统一在同一个循环中：

- 初始状态：`total` 只有 `2k` 个元素（比完整窗口少一个右边界）
- 每次迭代先补上右边界 → 窗口完整 → 计算 → 再移除左边界
- 这种设计避免了在循环外单独计算第一个窗口，结构更统一

#### 3.2 k = 0 的特殊情况

```python
total = sum(nums[0:0])  # = 0（空切片）
for i in range(0, n):   # 枚举每个位置
    total += nums[i]     # total = nums[i]
    ans[i] = total // 1  # = nums[i]
    total -= nums[i]     # total = 0
```

当 `k = 0` 时，窗口大小为 1（即元素本身），代码自然退化为返回原数组，无需特判。

#### 3.3 窗口过大时的自然绕过

当 `2k ≥ n` 时，`range(k, n - k)` 为空区间，循环不执行，直接返回全 `-1` 的结果。无需额外的边界判断。

---

### 4. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素在窗口进入和离开时各被处理一次，单次遍历完成。
- **空间复杂度**：$O(1)$（除输出数组外）。仅使用 `total` 一个额外变量。

### 延伸思考

- 本题与 [1456. 定长子串中元音的最大数目](../1456-maximum-number-of-vowels-in-a-substring-of-given-length/) 和 [0643. 子数组最大平均数 I](../0643-maximum-average-subarray-i/) 同为**定长滑动窗口**模板题，但本题的窗口是中心对称扩展（半径 k），窗口大小为 `2k + 1`，而前两题的窗口大小就是参数 k 本身。
- 也可用**前缀和**求解：预处理前缀和数组后 $O(1)$ 计算每个窗口的和。时间复杂度同为 $O(n)$，但需要 $O(n)$ 额外空间。滑动窗口在空间上更优。
- 代码中 `sum(nums[0:2*k])` 会创建一个临时切片（$O(k)$ 空间），可改为 `sum(itertools.islice(nums, 2*k))` 避免切片拷贝，不过对本题的数据规模影响不大。
- 本题使用整数除法 `//`；若要求精确平均值（浮点数），只需改为 `total / (2 * k + 1)` 即可。
